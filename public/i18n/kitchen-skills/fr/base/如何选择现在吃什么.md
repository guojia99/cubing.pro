# Comment décider quoi manger

Décider quoi manger est aussi l'une de mes grandes difficultés avant de cuisiner. Il ne me reste donc qu'à décrire le problème en termes mathématiques.

## Méthode de calcul

### Calculer le nombre de plats avec viande et de plats de légumes

* Nombre de plats = nombre de personnes + 1.
* Prévoyez un plat avec viande de plus que de plats de légumes, ou autant de chaque.

Une fois le nombre de plats avec viande et de plats de légumes déterminé, il suffit de choisir les recettes parmi celles de l'étape précédente.

#### Description en langage formel

Pour un nombre de personnes `N`,
notons `a` le `nombre de plats de légumes` et `b` le `nombre de plats avec viande`.
`N`, `a` et `b` sont des entiers.

On obtient alors le système suivant :

* a + b = N + 1
* a ≤ b ≤ a+1

Sa résolution donne :

```javascript
const a = Math.floor((N+1)/2);
const b = Math.ceil((N+1)/2);
```

### Choisir les plats

* Si vous êtes plus de 8 personnes, envisagez d'ajouter un plat de poisson parmi les plats avec viande.
* S'il y a des enfants, envisagez d'ajouter un plat à la saveur sucrée.
* Pensez à proposer des spécialités et des plats que vous maîtrisez particulièrement bien.
* Pour les plats avec viande, veillez à ne pas utiliser uniquement la viande d'un même animal. L'ordre à envisager est le suivant : `porc`, `poulet`, `bœuf`, `mouton`, `canard`, `poisson`.
* Ne choisissez pas d'animaux étranges pour vos plats avec viande.

Si vous hésitez encore, utilisez l'outil [Que manger aujourd'hui ?](https://github.com/ryanuo/whatToEat) pour choisir votre repas du jour.

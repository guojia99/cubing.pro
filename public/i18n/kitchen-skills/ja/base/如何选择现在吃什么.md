# 何を食べるかの決め方

何を食べるかを決めることも、私にとって料理を始める前の大きな難題です。そこで、数学を使って表してみることにしました。

## 計算方法

### 肉・魚料理と野菜料理の品数を計算する

* 料理の品数 = 人数 + 1。
* 肉・魚料理は、野菜料理より 1 品多いか、同じ品数にすれば十分です。

こうして肉・魚料理と野菜料理の品数が求まったら、前の段階のレシピから選べばよいわけです。

#### 形式言語による記述

人数が `N` のとき、
`野菜料理の品数`を `a`、`肉・魚料理の品数`を `b` とします。
`N`、`a`、`b` はすべて整数です。

このとき、次の連立不等式が成り立ちます。

* a + b = N + 1
* a ≤ b ≤ a+1

これを解くと、次のようになります。

```javascript
const a = Math.floor((N+1)/2);
const b = Math.ceil((N+1)/2);
```

### 料理の選び方

* 人数が 8 人を超える場合は、肉・魚料理の中に魚料理を加えることを検討します。
* 子どもがいる場合は、甘みのある料理を加えることを検討します。
* 特色のある料理や得意料理を加えることも考えましょう。
* 肉・魚料理を決める際は、すべて同じ種類の動物の肉にならないように注意してください。検討する順序は、`豚肉`、`鶏肉`、`牛肉`、`羊肉`、`鴨肉`、`魚肉`です。
* 肉料理に、奇妙な動物を選ばないでください。

それでも決められない場合は、[今日は何を食べる？](https://github.com/ryanuo/whatToEat)というツールで、今日食べるものを選んでください。

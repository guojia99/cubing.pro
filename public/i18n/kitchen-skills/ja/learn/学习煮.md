# ゆでる・煮る

## 手順

鍋に水を入れる → 火をつけ、鍋を火にかけて加熱する → 沸騰したら（水が激しく動き、大量の泡が出たら）食材を入れる

### 注意事項

* 加熱時にふたをすると、早く温まります。**ただし、吹きこぼれるおそれがあります**。加熱を続けると、激しく沸き立った液体が鍋の外にあふれ出ることがあります。これが吹きこぼれです。
* **吹きこぼれそうになったら、すぐに火を弱め、ふたを開けてください。**
* 早く温めながら吹きこぼれを防ぐには、ふたを少し開けて蒸気の逃げ道を作ります。また、後半で火を弱め、鍋の様子をこまめに確認する方法もあります。
* 調理の必要に応じて、食材を水から鍋に入れてもかまいません。ただし、その場合は沸騰するまでに時間がかかります。

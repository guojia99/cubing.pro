# 包丁の使い方を学ぶ

家庭の台所で料理を始める人のための、包丁の使い方の手引きです。目標は、安定して適切な大きさに切り、清潔と安全を保つことであり、速さを追求することではありません。まず安全上の注意と包丁の握り方を読み、それから扱いたい食材を選びましょう。硬い骨、硬い殻、かちかちに凍った食品は、別の道具を使うか、下処理済みのものを購入してください。

## 始める前に：まず台所を整える

1. 作業台を明るく清潔に保ち、十分な空間を確保します。子どもやペットは作業場所に近づけないでください。疲れているとき、飲酒後、集中できないときは包丁の使用を中断します。
2. 手を洗い、水気を拭き取ります。柄にぐらつきがないか、刃に欠けがないかを確認し、破損があれば使用をやめます。油や水で滑りやすくなった手で、そのまま包丁を握ってはいけません。
3. 傷みのない平らな木製、または食品用プラスチック製のまな板を選びます。下に滑り止めマットか固く絞った濡れ布巾を敷き、手で押して滑らないことを確かめます。ガラス、石材、陶磁器の皿の上では切らないでください。
4. 切る食材、切り終えた食材を入れる器、くずを入れる器を配置し、まな板の手前側が作業台からはみ出さないようにします。包丁を使わないときは、まな板の端から離れた位置に寝かせ、刃を人が触れない側へ向けます。
5. 生肉・生魚と、加熱済み食品・そのまま食べる野菜や果物には、別々の包丁とまな板を使います。1組しかない場合は、そのまま食べる食品を先に扱い、生肉を扱った後は十分に洗浄し、洗浄・消毒製品の説明に従って消毒してから、次の作業に移ります。
6. 一度に切る量は少なくします。生肉は数回に分けて冷蔵庫から取り出し、切ったら速やかに冷蔵するか調理します。練習のために長時間室温に広げておかないでください。

## 必ず身につけたい安全習慣

- 包丁が落ちたら離れ、絶対に手で受け止めたり足で止めたりしません。落ちて動かなくなってから拾います。
- 包丁で人を指したり、身振りをしたり、持ったまま振り向いて話したりしません。食材を移す、電話に出る、戸棚を開けるときは、先に包丁を置きます。
- 洗い物の水、泡、布巾、食材の下に包丁を隠しません。引き出しの中にむき出しのまま無造作に入れないでください。
- できるだけ決まった場所で作業します。どうしても移動する場合は切っ先を下に向け、刃を自分や周囲の人から遠ざけ、もう片方の手で同時に重い物を運ばないでください。人混みをすり抜けないようにします。
- 包丁を渡すときは、まず安定した台の上に置き、相手が柄を握ってから持ち上げてもらいます。切っ先を相手に向けて渡してはいけません。
- 調理用包丁で缶を開ける、瓶のふたをこじ開ける、ねじを回す、硬い殻をむく、包装を開けることはしません。刃が挟まったら力を加えるのをやめ、包丁をねじったり、峰をたたいたり、食材ごと持ち上げてまな板に打ちつけたりしないでください。
- よく切れる包丁でもけがはします。「切れ味を保つ」のは、滑りや無理な力を減らすためであり、手の保護をおろそかにしてよいという意味ではありません。
- 耐切創手袋でも、すべての刺し傷や打ち切りによるけがを防げるわけではありません。使う場合は食品との接触に適した、サイズの合う製品を選び、説明に従って洗い、正しい握り方も守ります。

## 包丁の種類：作業に合わせて選ぶ

| 包丁・道具 | 向いている作業 | 向いていない作業 |
| --- | --- | --- |
| 中華薄刃包丁、桑刀 | 野菜や骨なし肉の薄切り・細切り。幅広の刀身は食材を移すのにも便利 | 骨をたたき切る、硬く凍った肉を切る。幅広の見た目でも骨を切れるとは限らない |
| 牛刀 | 日常の薄切り、ぶつ切り、みじん切り。湾曲した刃は小さな揺らし切りに便利 | 殻をこじ開ける、硬い骨をねじり切る。特に薄い刃は傷みやすい |
| 三徳包丁 | 野菜、魚、骨なし肉の日常の下ごしらえ | 無理に切っ先を支点にして揺らし切りする、力任せに骨をたたき切る |
| 皮むきナイフ、小型の果物ナイフ | 小さい食材の形を整える、へたを取る。初心者はこれらもまな板の上で使う | 硬い食材を手のひらに持ち、素早く皮をむいたり切ったりする |
| 波刃ナイフ、パン切り包丁 | パンやよく熟して柔らかいトマトなどを、軽くのこぎりのように動かして切る | 骨をたたき切る。長い刃を前後に動かすときは、もう片方の手を特に進路から遠ざける |
| 骨すき包丁、魚用フィレナイフ | 熟練者が骨に沿って肉を外す、魚をおろす。刃のしなりや硬さは用途によって異なる | 初心者が肉を素手で持ち、手のひらに向かってそぎ切りする |
| 骨切り用の厚刃包丁 | メーカーが明確に認める骨の処理 | 万能包丁として使う。すべての骨を家庭で処理できるわけではない |
| キッチンばさみ | ねぎ、包装、メーカーが認める軟らかい組織を切る | 想定用途を超えて硬い骨を切る。生の食品に使った後、洗わずに加熱済み食品を切る |

初心者は通常、安定して握れる主な包丁1本、小型ナイフ1本、安定したまな板から始めれば十分です。パンをよく食べるなら波刃ナイフを追加します。入門のために一式そろえる必要はありません。まず用途の説明を確認し、次に長さ、重さ、柄が自分の手に合うかを見ます。刀身が長すぎたり重すぎたりすると、扱いが難しくなります。

ステンレスの包丁もさびます。炭素鋼の包丁は特に速やかに水気を拭き取る必要があり、表面の正常な酸化による変色と赤褐色のさびは別物です。セラミック包丁は硬くてもろいため、ねじり切り、にんにくをたたきつぶす作業、骨や硬く凍った食品の切断には向きません。研ぎは通常、専門家に任せます。

## 包丁の部位と握り方を知る

### 包丁を持つ手：安定を優先

峰は刃の反対側にある厚い辺で、切っ先は前端、あごは柄に近い刃の端です。あごも非常に鋭い包丁があるので、指を刃先の下に回してはいけません。

柄を握る方法：指で柄を包み、親指を自然に収め、指が前へ滑って刃に触れないようにします。練習を始めたばかりのときや、つまみ持ちに向かない形の包丁に適しています。

つまみ持ち：親指と人差し指で柄に近い刀身の両側を軽くつまみ、残りの指で柄を握ります。指の腹は下側の刃先から離します。その包丁の形に適し、安定して持てる場合に使います。切っ先や刃をつまんだり、指を前に伸ばしすぎたりしないでください。

握る力は包丁が回らない程度にし、手首がこわばるほど握りしめません。手首をなるべく自然に保ち、肩の力を抜きます。食材が高すぎたり硬すぎたりする場合は、腕を高く上げて力を加えるのではなく、先に食材の形を変えます。

### 添える手：猫の手は防具ではない

1. 指先を手のひら側へ曲げて食材を押さえ、指の関節を包丁の側面へ向けます。
2. 親指は食材の後ろ側に収め、刃の前に出しません。小指も広げないようにします。
3. 包丁の側面を曲げた指の関節に軽く当て、位置の目安にすることはできますが、刃先は常に案内役の関節より低く保ちます。包丁を関節より高く持ち上げないでください。
4. 1回切るごとに、まず包丁を止めてから、添える手を少し後ろへ動かします。包丁を追いかけるように手を動かしてはいけません。
5. 残りが短く小さくなったら止め、寝かせて向きを変えるか、別の用途に取っておきます。最後の1ミリまで切る必要はありません。

滑りやすい肉、丸い食材、指で安定して押さえられない小片は、まず表面の余分な水分を拭く、平らな底を作る、道具を替えるなどします。「猫の手」だけを頼りに無理に切らないでください。

## 基本の切り方と大きさ

寸法は理解の助けであり、統一規格ではありません。具体的なレシピや火の通し方に合わせてください。同じ鍋に入れる同じ種類の食材は、できるだけ大きさをそろえ、外側が焦げても中は硬いといった状態を避けます。

| 切り方 | 方法 | よく使う用途と例 |
| --- | --- | --- |
| 薄切り | 平らな底をまな板につけ、安定して刃を入れ、その都度手を後ろへ引く | 炒めるじゃがいもの薄切りは約 2—3 ミリから練習できる。厚さはレシピに合わせて調整 |
| 拍子木切り・細切り | まず薄切りにし、少量をそろえて重ねるか広げてから、細長く切る | 初心者は太めの棒状から始め、慣れたら細くする |
| さいの目切り | 棒状の食材の向きを変え、横に切る | 付け合わせのさいの目は約 1 センチから練習できる。一度に何層も重ねない |
| ぶつ切り | ほぼ同じ大きさの塊に分ける | 煮込み用は通常、短時間の炒め物より大きく切る。具体的にはレシピに従う |
| 乱切り | 細長い食材を斜めに切り、回してから再び斜めに切る | にんじん、なす。回すときは毎回、先に刃を離して確実に止める |
| みじん切り | 薄切り、細切り、小さいさいの目の順にし、少量ずつ細かく刻む | しょうが、にんにく、ハーブ。添える手を刃先の近くに置かない |
| 引き切り・押し切り | 刃を水平方向にも動かして切り込み、真下へ力任せに押し続けない | 骨なし肉、比較的柔らかい野菜。動かす範囲がもう片方の手に触れないようにする |
| 軽いのこぎり切り | 波刃ナイフを前後に動かし、下へ押す力を減らす | パン、柔らかいトマトをつぶさずに切る |

揺らし切りは、包丁の形、作業空間、食材のすべてが適している場合に限ります。柄を小さく動かし、制御を保ち、連続した速い刻み切りを追求しません。刃が直線的な包丁で、湾曲した牛刀の動作をまねる必要はありません。

食材を移すときは、スクレーパーや手を優先します。刀身を使う場合はまず包丁を止め、刃先を指から遠ざけ、切れ味を落とす原因となる、まな板上での刃先の横滑らせを避けます。付着した食材を指で刃に沿ってぬぐい落としてはいけません。

## 野菜を切る：安定する平面から始める

### じゃがいも・にんじん・大根：平らな底を作ってから、薄切り・細切り・さいの目に

1. 洗い、必要に応じて皮をむき、食べられない部分を除きます。緑色になったもの、明らかに芽が出ているもの、傷んだじゃがいもは、練習にも食用にも使わないでください。
2. 円柱形のにんじんは、先に扱いやすい長さに切ってもかまいません。薄く1枚切り落として平らな底を作り、その面を下にして切ります。
3. まず厚さのそろった薄切りにします。細切りにする際は、安定する少量だけを重ね、滑る場合は広げて1枚ずつ切ります。
4. さいの目切りは、幅をそろえた棒状にしてから横に切ります。長い大根を立てて、上からたたき切ってはいけません。

![丸い食材にまず平らな底を作り、寝かせて薄切り、棒状、さいの目に切る](images/knife-cuts.svg)

### 玉ねぎ：初心者は手のひらに向かう横方向の切り込みを入れない

1. 外皮と乾いた先端を取り、根を通る方向に半分に切ります。最初の一刀を入れるときは玉ねぎを安定させ、必要なら小さな平面を削り出します。
2. 半分の玉ねぎの切り口を下にし、根元を奥に向けます。先端から根元へ向かう方向に数本切り込みを入れ、根元近くを少しつなげておきます。
3. 向きを変えて横に切り、さいの目にします。玉ねぎ自体の層を利用するので、手のひらに向かう水平の切り込みを加える必要はありません。
4. 根元近くになったら止め、押さえにくい端は別に寝かせて処理するか、捨てます。

目を閉じて玉ねぎを切ってはいけません。涙で見えにくくなったら、まず包丁を置いてまな板から離れ、視界が戻ってから続けます。

### ピーマン・パプリカ・唐辛子

安定させて縦に割り、寝かせて種と白い筋を除いてから、細切りやさいの目にします。皮側が滑る場合は内側を上にします。唐辛子を扱った後は目に触れないようにしてください。食品用の手袋を使ってもよく、作業後は手を洗い、包丁とまな板を洗浄します。

### トマト・なす・きゅうり

トマトはよく切れる薄刃の包丁で軽く引き切りするか、波刃ナイフで軽く前後に動かして切ります。滑るからといって急に力を加えてはいけません。きゅうりとなすは先にへたを取り、縦に切って安定する底面を作るか、半分にして寝かせます。乱切りでは少量ずつ切り、毎回包丁を止めてから回し、食材が刃先へ転がらないようにします。

### 葉物野菜・ねぎ・ハーブ

まず洗って余分な水を切り、傷んだ葉を除きます。葉物は少量を重ねて軽く巻き、ざく切りや細切りにします。高い山になるほど巻き重ねないでください。ねぎは短く切ってからそろえ、白い部分が滑る場合は一度に扱う量を減らします。ハーブは先に寄せ集め、刃を下ろしている最中に散った葉を拾おうと手を出しません。

### しょうが・にんにく・きのこ

しょうがは平らな底を作り、薄切り、細切り、みじん切りの順に切ります。にんにくは皮をむいて薄切りやみじん切りにするか、ガーリックプレスを使います。初心者が刀身で強くたたきつぶす動作をまねるのは勧めません。特にセラミック包丁や薄くもろい包丁では行わないでください。きのこは不要な根元を除き、大きいものは半分にして切り口を下にします。小さくて固定しにくいものは、レシピに合わせて丸ごと調理してもかまいません。

### かぼちゃ・冬瓜・とうもろこしなどの硬い食材

大きなかぼちゃや硬い皮のある瓜類では、安定性と道具の適合が最も重要です。初心者はカット済みのものを優先しましょう。切り開くために峰をたたく、包丁を足で踏む、持ち上げてまな板に打ちつけることはしないでください。刃が入ったまま挟まったら止め、左右にねじりません。

とうもろこしの粒は専用の粒取り器で外せます。包丁を使う場合は、先に安定して置ける短い長さにし、低い位置で固定して、食材を持つ手から刃を遠ざけ、面ごとにそぎ落とします。安定して固定できなければ、粒状のものを購入します。丸ごと1本を滑らかな台の上に高く立てて削らないでください。

## 肉を切る：繊維と骨の有無を確認する

### 骨なしの牛肉・豚肉：繊維を断つように薄切りにする

肉に見える細長く平行な筋が繊維の向きです。繊維を断つとは、切り口が繊維を横切るようにして、一口の肉に含まれる長い繊維を短くすることです。体に対して決まった方向に切るという意味ではありません。

1. 生肉は冷蔵下で解凍します。硬く凍った肉を切ったり、柔らかくなるまで長時間室温に置いたりしないでください。
2. 表面の余分な肉汁を拭き取り、生肉専用の包丁とまな板を使い、切った肉は速やかに容器へ入れます。
3. 繊維の向きをよく見て、繊維を横断しやすい向きに置きます。平らな底がなければ、先に安定して寝かせられる塊に分けます。
4. 安定した引き切りで、厚さのそろった薄切りにします。炒め物用なら約 2—4 ミリから練習できますが、レシピに合わせて調整します。肉を手で宙に持ち上げて引っ張り、手に向かって切ってはいけません。
5. 細切りは先に薄切りにしてから棒状にし、煮込み用は大きさのそろった塊にします。部位によって繊維の向きが変わることがあるので、肉を回して改めて確認します。

![筋繊維は平行に伸びており、切る線を繊維と交差させて繊維の長さを短くする](images/knife-grain.svg)

「牛は横、豚は縦」といった覚え方は、部位やレシピの確認の代わりにはなりません。繊維を断つか、厚さをどれくらいにするか、形を保つ必要があるかは、料理の仕上がりに合わせて判断します。柔らかさを求める骨なし肉の短時間の炒め物では、繊維を短くすると一般にかみやすくなります。

### 鶏むね肉・鶏もも肉・骨付き鶏肉

鶏むね肉は寝かせ、目立つ筋膜を除いてから薄切りやぶつ切りにします。初心者は手のひらを肉の上に押し当てて水平に薄くそがず、薄切り済みの肉を購入してもよいでしょう。鶏もも肉は骨なしを優先し、広げてから切り分けます。薄刃の包丁で関節、脚の骨、冷凍の鶏肉を無理にたたき切らず、販売店で切り分けてもらってください。

生の鶏肉は、水はねで周囲を汚染しないよう、洗い流さないでください。生の鶏肉を切った後は、手、包丁とまな板、作業台、触れた取っ手を洗浄します。生肉を載せた皿に、そのまま加熱済みの肉を載せてはいけません。薄く切ったからといって安全に火が通ったことにはならず、調理では引き続きレシピと食品安全上の要件に従う必要があります。

### 魚・えび・魚介類

入門には骨を除いた魚の切り身を優先します。余分な水分を拭いて寝かせ、身を押しつぶさないよう優しく引き切りします。骨を見つけたら専用の骨抜きで取り除き、確認します。「骨なし」の表示だけを頼りに確認を省略してはいけません。

丸魚の骨や皮を取る作業、貝を開く作業には、滑り、鋭いとげ、専用道具の扱いが伴うため、販売店に任せてもかまいません。えびはキッチンばさみで背を開いてから、必要な部分を取り除けます。手のひらに握り、先のとがった包丁を手に向けて刺さないでください。かき、ココナッツ、かにの殻などを普通の調理用包丁で無理にこじ開けてはいけません。

### 加熱済みの肉・残り物

清潔で生肉に触れていない包丁とまな板を使い、肉の繊維やレシピに合わせて切ります。加熱直後の熱い肉を手で強く押さえず、扱える温度になってから切り、同時に長時間室温に置くことを避けます。切った残り物は速やかに適切に冷蔵します。

## 果物・パン・豆腐・その他の食材

### りんご・梨・かんきつ類

洗ってからまな板の上で切り分けます。りんごと梨はまず平面を作り、くし形に切り、寝かせてから芯を取ります。果実片を手のひらに載せ、手のひらに向けて芯をそぎ取ってはいけません。かんきつ類は手でむけるなら手でむき、輪切りにする必要がある場合は先に安定する底面を作ります。

### アボカド・マンゴー・種のある果物

熟したアボカドは専用道具を優先して使ってもよいでしょう。包丁を使う場合はまな板の上で果実を安定させ、種の周囲をゆっくり切り、包丁を止めてから手で半分に分け、スプーンで種と果肉を取ります。半分の果実を手のひらに持ち、包丁を種に打ち込んだり、切っ先で種をほじり出したりしてはいけません。

マンゴーは先に安定する底面を作り、平たい種の両側に沿って果肉を切り離します。小さく切るときは果肉を皮から外してまな板に置いてから切ります。皮を手に持ったまま格子状の切り込みを入れると、切っ先が皮を貫いて手を刺すおそれがあるので、行わないでください。桃やすももなどは切り開いてから手で分けるかスプーンで種を取り、包丁で無理にこじりません。

### すいか・パイナップル・硬い殻の果実

大きなすいかやパイナップルは、まず重さとまな板の大きさを考え、扱いきれなければカット済みのものを購入します。安定して作業できる場合は、先に平らな底を作り、小さく分けてから皮を落とします。転がる大きな果実を丸ごと横方向に力任せに切りつけてはいけません。ココナッツなどの硬い殻には専用道具と適切な作業条件が必要で、普通の調理用包丁は適していません。

### パン・ケーキ・豆腐・チーズ

パンは波刃ナイフを軽く前後に動かして切り、押さえる手を刃の前後の進路から遠ざけます。下に近づくほど力を弱め、突然突き抜けるのを防ぎます。ケーキは清潔な長い包丁で安定して切り、包丁を止めてから付着物を拭き取ります。

豆腐はまな板にそっと置き、薄くよく切れる包丁で切り分け、手で押しつぶしません。チーズが刃にくっつく場合は一度に切る厚さを減らすか、適切なチーズナイフを使い、包丁をねじって大きな塊をこじり割らないでください。ナッツの硬い殻には専用の殻割りを使い、氷や硬いあめも調理用包丁でたたき切ってはいけません。

## 洗浄・乾燥・収納

1. 使い終えたらすぐ、包丁はほかの洗い物と分けて扱い、柄を握って、刃を体ともう片方の手から遠ざけます。
2. ぬるま湯、中性などの穏やかな洗剤、刀身を傷つけにくい洗浄道具で洗います。刃先に向かわない方向に洗い、スポンジや布巾で刃を包んで往復させたり、素手で刃先を拭いたりしません。
3. 生の食品で汚染された包丁とまな板は、まず汚れを落として洗い、その後、用途に合った消毒製品の説明に従います。濃度、接触時間、すすぎの要否は製品の指定に従い、洗浄剤をむやみに混ぜないでください。
4. すすいだ後、刃先を避けながら刀身、柄との接合部、柄を慎重に拭いて乾かします。長時間水につけず、食器洗い機は勧めません。特に木製の柄、炭素鋼、メーカーが機械洗浄を禁じる包丁では避けてください。
5. 完全に乾いたら、さや、包丁立て、独立した収納溝のある引き出しに収めます。包丁立ても清潔で乾いた状態にします。マグネット式ホルダーはしっかり固定して子どもから遠ざけ、刃先がぶつからないようメーカー指定の方法で着脱します。

木製の柄はメーカーの説明に従い、食品との接触が認められた手入れ用品で管理します。自己判断で工業用機械油を塗らないでください。炭素鋼の包丁は酸性の食材を切ったら速やかに洗って拭き、長期保管時に食品用の防さび油を薄く塗るかどうかは説明に従い、使用前に洗浄します。さび、ひび、柄のぐらつき、目立つ刃こぼれが見つかったら、まず修理または交換します。

## 研ぎ・刃の整え方・切れ味の判断

### 手入れが必要なタイミング

同じ食材でも以前より力が必要、トマトを切るといつも滑る、ねぎの葉が切れずにつぶれる場合は、刃の手入れが必要かもしれません。同時に、包丁の選択が違っていないか、まな板が滑っていないか、食材に平らな底がないままになっていないかも確認します。

指を刃に滑らせる、毛をそる、手の上で紙を切るといった試し方はしないでください。まな板の上で普通の食材を通常の方法で切り、滑らかに切れるかを確認できます。刃こぼれがある場合は試し切りを続けません。

### ホーニングロッドと砥石の違い

鋼製のホーニングロッドの一部は、主にわずかに曲がった刃先を整えるものです。セラミック棒やダイヤモンド棒は金属を削り取ることもあります。刃の材質、硬度、形によって必要な道具は異なり、日本式の薄刃、片刃、セラミック包丁には、ほかの包丁の手入れ方法をそのまま当てはめられません。

砥石は少量の材料を削り取って刃先を回復させます。すべての包丁に共通する角度の数字はなく、メーカーが示す片側の角度、刃の形、研ぎ道具の説明を優先します。両側を合わせた角度を片側の角度と取り違えると、刃を傷めます。

### 初心者の手入れ手順

1. 包丁の説明書を確認し、自分で研げるか、適した道具と角度は何かを確かめます。不明な場合は専門の研ぎサービスに任せます。
2. 砥石やガイド付き研ぎ器を滑り止め付きの台座に固定し、台を清潔にして十分な明るさを確保します。浸水、水の追加、油の使用の要否は研ぎ道具の説明に従い、すべての砥石を水につけることはしません。
3. ガイド付きの道具を使うか、習得した安定した動作で軽く研ぎ、指は常に刃の移動経路から離します。研ぎ棒を宙に構えて包丁を素早く振り回すような見せ技はしないでください。
4. 切れ味を求めて強く押したり、刃先を薄くしすぎたりしません。波刃、片刃、セラミック包丁は、それぞれの刃に詳しい人に手入れを任せます。
5. 終わったら包丁と作業台の金属の研ぎくずを洗い落とし、拭いて収納します。研いだ包丁は使用感が変わるので、まず少量の食材をゆっくり切ります。

研ぐ頻度は使用量、刃の材質、まな板、使い方によって変わり、決まった日数ごとに研ぐ必要はありません。適切なまな板を使い、刃先を横にこすらず、個別に収納することのほうが、頻繁に研ぐより大切な場合が多くあります。

## よくある問題の確認

| 問題 | 最初に確認すること | より安全で確実な対処 |
| --- | --- | --- |
| 食材が転がる | 平らな底がない、まな板が滑りすぎる | 包丁を止め、平らな底を作り、まな板を固定する |
| 刃が皮の上で滑る | 刃が鈍い、表面が濡れている、包丁が適切でない | 余分な水分を拭き、よく切れる包丁か適切な波刃ナイフに替える |
| 薄切りの厚さがばらつく | 重ねすぎ、手を引く幅が不ぞろい、動作が速すぎる | 量を減らし、一刀ごとに止め、厚めの薄切りから練習する |
| 肉が押しつぶされる | 刃が鈍い、肉が柔らかすぎる、真下へ力任せに押し続けている | 冷蔵してしっかりした状態を保ち、よく切れる包丁で安定して引き切りする |
| 硬い食材に包丁が挟まる | 作業が包丁の能力を超えている | ねじる、こじる、たたく動作をやめ、カット済み食材を買うか販売店に任せる |
| 手首が痛む | 包丁が重すぎる、台の高さが合わない、握る力が強すぎる | 中断して休み、道具と姿勢を調整し、痛みが続く場合は速やかに受診する |
| 食材が刃にくっつく | 切り口が濡れている、でんぷんを含む | 包丁を止めてから適切な道具で外し、刃に沿ってぬぐわない |

## 段階的な練習：時間を計らず、速さを競わない

1. 第1段階は、作業台の準備、握り方、猫の手、包丁を止めることだけを練習します。固定しやすい半分のきゅうりや、適度な硬さの野菜を選び、少量を厚めに切ります。
2. 第2段階は、平らな底のあるじゃがいもで薄切り、棒状、さいの目を練習します。大きさがおおむねそろっていれば十分で、髪の毛ほどの細さは求めません。
3. 第3段階は、玉ねぎのさいの目、ピーマンの細切り、葉物のざく切りを練習し、食材ごとの安定させ方を体感します。
4. 第4段階は、生肉専用の包丁とまな板で骨なし肉の薄切りを練習します。まず繊維を見分け、少量を切り、最後に洗浄と消毒を済ませます。
5. 毎回終わったら振り返ります。まな板は動かなかったか、親指が出ていなかったか、力任せに包丁を押さなかったか、小さな端まで来たときに自分から止めたか、包丁をすぐに片づけたかを確認します。

各段階で安定してゆっくり作業できることを、次の段階へ進む条件にします。未成年者には、操作能力のある大人がその場で指導し、年齢と能力に合った道具と作業を選んでください。

## 誤って切ってしまったとき

すぐに包丁を置き、食材に触れるのをやめます。小さな傷は清潔なガーゼなどの被覆材や布で直接、持続的に圧迫して止血できます。刺さった物がある場合は自分で抜いたり異物の真上を押したりせず、周囲を圧迫して受診します。被覆材に血が染み通ったら上からもう1枚重ね、何度もめくって確認しないようにします。

止血後、小さく浅い傷は清潔な流水で洗い、周囲の皮膚を清潔にしてから滅菌された被覆材で覆います。傷から汚染された食品は捨て、汚染された作業台を清掃します。傷に塩やコーヒー粉をまいたり、食材を使う民間療法を試したりしないでください。

出血が止まらない、血が噴き出す、傷が深い・大きい、手のひらの重いけが、しびれ、動かしにくさ、異物がある場合は、直ちに医療の助けを求めてください。中国本土で緊急の場合は 120 に電話します。その後、赤みや腫れの悪化、膿、発熱などが出た場合も受診し、感染や破傷風予防の必要性を医療従事者に評価してもらいます。文章の手引きは、実地の応急手当訓練の代わりにはなりません。

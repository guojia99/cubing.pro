
# 炒める／焼く

## 器具

一般的な金属製（鉄／ステンレス／アルミニウム）の中華鍋やフライパン、または焦げ付き防止加工の鍋を使えます。

アルミニウム製の容器はおすすめしません。理由は食品安全の節を参照してください

### 注意事項

* 普通の鍋で炒め物をするときに焦げ付きを防ぐ方法：

#### 先に卵を炒める方法

* どんな料理を炒める場合でも、先に卵を1個炒めます。炒め終わったら鍋を洗わずに次の料理を炒めると、焦げ付きません。

#### 熱した鍋に冷たい油を入れる方法

* 必ず「熱い鍋に冷たい油」を入れることを覚えておいてください。まず鍋を熱します
  * 清潔な鍋に何も入れずに空焼きし、均一に熱が伝わるようにして十分に熱します
  * 冷たい油を入れて鍋を回し、鍋全体に油を行き渡らせます（前後に回して均一に熱してもかまいません）
  * 鍋から煙が出るのが見えたら、鍋の油が熱くなった合図です
  * 油をあけます。油をあけた後は、鍋を洗わないでください
  * 上の手順を 2-3 回繰り返すと、焦げ付き防止の効果をより高められます
  * 注意：ガス火の場合、炎が上がることがあるので、安全に注意してください

#### 熱した鍋に油を2回に分けて入れる方法

* まず鍋を熱します
  * 清潔な鍋に何も入れずに空焼きし、均一に熱が伝わるようにして十分に熱します
  * 「少量の冷たい油」を入れて鍋を回し、鍋全体に油を行き渡らせます（前後に回して均一に熱してもかまいません）
  * 鍋から煙が出るのが見えたら、鍋の油が熱くなった合図です
  * さらに冷たい油を加え、炒め始めます
  * 注意：ガス火の場合、炎が上がることがあるので、安全に注意してください。

補足：

* 目的は、鍋底全体に油の膜を作ることです。市販の家庭用鍋すべてに使え、油の膜を作れば、あっという間に焦げ付き防止鍋に早変わりします。
* 焦げ付き防止加工の鍋で焼いたり炒めたりすると、食材がくっつきません。この機能は鍋の内側のコーティングによるものです。**金属製のへらはコーティングを傷付けます。焦げ付き防止加工の鍋を使うときは、コーティングを傷めないよう、木製またはシリコーン製のへらを使ってください。**

### 手順

火をつける → 鍋を火の上に水平に置いて熱する → 鍋に油を入れて熱する → 食材を入れて炒め合わせる → 鍋から取り出す前に調味料を入れるのを忘れずに

### 注意事項

* 鍋や油が熱くなったかどうかを判断するときは、鍋の上に手を水平にかざして熱を感じ取れます。食材を入れるのは油が熱くなってからにしてください。
* 鍋に油を入れる前に、鍋の内側に水分が残っていないことを必ず確認してください。**水があると熱い油が飛び散り、危険です。**
* 上の項目に関連して、食材を油の入った鍋に入れる前に、水気を切ってください（卵液は問題ありません）。同様に、解凍していない食材を油の入った鍋に入れないでください。氷が溶けると危険です。
* **油の入った鍋から火が出た場合、絶対に水をかけて消そうとしてはいけません**。火の勢いが強まってしまいます。火が出た直後なら、すぐに火を止め、鍋のふたをしてください。

# 蒸す

## 方法

### 蒸し器

蒸し器は何段にも重なる構造で、一番下に水を入れます。水が沸騰して発生する蒸気の熱を利用し、上段の食材を加熱します。

蒸し器の最下段に適量の水を入れる → 上段の蒸し段に食材を置く → 蒸し器を火にかけて加熱する

### 鉄鍋

蒸し器がなく、普通の鉄鍋（底が平らでないもの）しかない場合は、鍋底に三脚式の蒸し台を置き、十分な水を入れると、蒸し器と同じような効果を得られます。

鉄鍋の底に十分な水を入れる → 三脚式の蒸し台を入れる → 蒸し台の上に食材を置く → 火をつけてふたをする

## 注意事項

* 熱源が水蒸気なので、下のほうの蒸し段では食材の底が水でぬれることがあります。食材の下に蒸し布を敷くと、このような状態を防げます。箸を組んで食材を載せる簡単な台を作ってもかまいません。
* スマートデバイスでタイマーを設定し、火を止めるタイミングを知らせるようにすると、火を止め忘れて水がなくなるのを防げます。
* せいろで食品を調理する際は、底の部分に残っている水の量に注意してください。**特に鉄鍋の場合は注意が必要です**。空だきによる安全上の問題を防ぎましょう。
* （任意）鉄鍋で食材を蒸す場合は、三脚式の蒸し台の上に蒸し皿を置いてもかまいません。

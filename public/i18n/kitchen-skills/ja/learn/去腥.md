# 臭み取り

臭み取りは、料理を作る過程の一工程です。

臭み取りとは、調味料の添加や下ゆでなどをはじめとする方法で、肉類や水産物などの食材から生臭さや獣臭さを取り除くことです。

**生臭さや獣臭さは、一部の食材では風味のもとでもあります。臭みを取りすぎると、食材の風味が失われることがあります。**

臭み取りの方法はさまざまなので、調理の過程で柔軟に選びましょう。

## 方法

### 調味料を加える

食材に調味料を加えるのは、最も簡単な臭み取りの方法です。例えば、溶き卵を使う料理の多く（[中華風茶碗蒸し](../../dishes/vegetable_dish/鸡蛋羹/鸡蛋羹.md)、[トマトと卵の炒め物](../../dishes/vegetable_dish/西红柿炒鸡蛋.md)）では、卵液を作る際に塩、料理酒、食酢などの調味料を加えることで臭みを取れます。

一部の肉類を調理するときは、スープに花椒、八角、ローリエ、桂皮、フェンネルシード、唐辛子などの香辛料を加えて臭みを取ることができます。

市販の麻辣火鍋の素は非常に香りが強く、調理時に適量加えることで、ほとんどの肉類の臭みを覆い隠せます。

### つけだれ

食材によっては、調理後も強い臭みが残ります。つけだれを作り、食べるときに臭みを覆い隠すことができます。

つけだれによく使われる材料には、食酢、醤油、ごま油、豆板醤、甜麺醤、練りごま、ピーナッツバター、腐乳、食塩、にんにく、しょうがなどがあります。

つけだれの組み合わせは人それぞれなので、ここでは例を挙げません。

### 香味野菜を炒めて香りを出す

炒め物では、ねぎ、しょうが、にんにく、乾燥唐辛子などの香味食材を鍋で炒め、香りを出すことができます。香味食材に含まれる香り成分が高温によって揮発し、ある程度臭みを覆い隠すとともに、料理の風味を増してくれます。

### 水から下ゆでする

鶏肉、豚足、スペアリブなど、一部の動物性食材には血液が残っています。残った血液を取り除かないと、料理に多少の臭みが出ます。

水から鍋に入れると、残った血液が水中に分散します。温度が上がるにつれて血液中のたんぱく質が凝固し、水中に分散していた血液がアクとなって水面に浮かびます。このとき、お玉でアクをすくい取るだけで臭み取りができます。残った澄んだスープは、煮込み料理のベースとして引き続き使えます。

### 注意事項

- 下ゆでの際は、花椒、八角、料理酒、長ねぎなどの調味料を鍋に加え、臭み取りの効果をさらに高めることがよくあります
- 八角は香りが強いので、適量を加えてください
- 花椒や麻椒は粒が小さく、加える量も多いため、鍋の中や完成した料理に残ることがあります。ガーゼで包んで香辛料袋にするか、食品用ステンレス製のスパイスケースを使うと、料理ができあがる前に取り出しやすくなります

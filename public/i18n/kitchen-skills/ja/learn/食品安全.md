# 食品の安全

## 中毒

以下の食品には、中毒を引き起こすリスクがあります：

* 未熟な青いトマト
* 十分に加熱されていないインゲンマメ、ササゲ、[ナタマメ](https://zh.wikipedia.org/wiki/%E7%99%BD%E5%88%80%E8%B1%86)
* 芽が出たジャガイモ（ヤマイモ）、サツマイモ（カンショ）、ピーナッツ
* 適切に下処理されていない、または十分に加熱されていない[金針菜](https://zh.m.wikipedia.org/wiki/%E9%BB%84%E8%8A%B1%E8%8F%9C)は、[コルヒチン](https://zh.m.wikipedia.org/wiki/%E7%A7%8B%E6%B0%B4%E4%BB%99%E7%B4%A0)中毒を引き起こすことがあります
* 加熱していない豆乳
* 水で戻す時間が長すぎたキクラゲ（キクラゲに限らず、すべてのキノコ類は戻す時間が長すぎると中毒のリスクがあります）
* 十分に火を通していない動物の内臓
* 種類のわからないキノコ、または十分に加熱されていないキノコ（「赤い傘に白い柄、食べればみんなで棺の板の上」ということわざがあります。一般に、見た目が美しいキノコほど危険です。）
* ……（追記歓迎）

酸性の食品をアルミニウム製の容器で長時間保存・調理することにも、中毒を引き起こすリスクがあります。例えば：

* 酸菜（野菜の発酵漬け）
* 干しタケノコ
* トマトソース
* レモン汁
* 肉の中国風香辛料煮込み
* しょうゆやしょうゆ漬けの野菜
* ……（追記歓迎）

## アレルギー

以下は、よくあるアレルギーの原因食品です（注意：アレルギー反応は一般に一生続きます）：

成人：

* エビ、カニ、貝類などの魚介類（鮮度が落ちて細菌が増殖した魚介類を食べること）
* ピーナッツ
* ナッツ類
* 魚類

子ども：

* ピーナッツ
* ナッツ類
* 卵類
* 牛乳（主に牛乳中の A1 タンパク質に対する不耐症）
* 小麦と大豆

## サルモネラ感染症

サルモネラは動物由来の食品で比較的よく見られます。野菜にも、糞便による汚染によってサルモネラが含まれる可能性があります。

以下の食品には、サルモネラ感染症を引き起こすリスクがあります：

* 十分に加熱されていない卵
* 十分に加熱されていない肉
* 殺菌されていない乳

## アフラトキシン

アフラトキシンは、アスペルギルス・フラバスやアスペルギルス・パラシチカスなど数種類のカビによって、米、豆類、ピーナッツなどのカビが生えた穀物中でよく生成される、これまでに知られている中で最も強力な発がん性物質です。280℃以上に加熱して初めて分解が始まるため、通常の加熱ではその構造を壊しにくいです。

以下の食品には、アフラトキシン中毒を引き起こすリスクがあります：

* 傷んだピーナッツ
* 傷んだ米
* 傷んだトウモロコシ

上記の食品には、米粉やトウモロコシ粉など、それぞれの加工品も含まれることに注意してください。安全に栽培・生産されたピーナッツの芽（発芽ピーナッツ）は、安全に食べられると考えられます。

## 3-ニトロプロピオン酸

3-ニトロプロピオン酸は、サトウキビに発生するアルスリニウム・サッカリ菌によって生成されます。この真菌は、サトウキビやココナッツによく寄生します。中毒の主な症状は中枢神経系の損傷です。急性期には嘔吐、めまい、発作性のけいれん、眼球の片側への共同偏視、昏睡、さらには死亡に至ることもあります。後遺症は主に錐体外路系の損傷で、主な症状には屈曲、ねじれ、けいれん、四肢の硬直、安静時の筋緊張低下などがあります。この毒素に対する特効解毒薬は、現在ありません。

以下の食品には、3-ニトロプロピオン酸中毒を引き起こすリスクがあります：

* 中心が赤くなったサトウキビ
* [傷んだココナッツ](https://www.bilibili.com/video/BV1w84y147TU)

見た目だけでなく、においも重要な判断基準です。傷んだ植物性食品は、特有のにおい（酒かすのようなにおい、酸っぱいにおいなど）を発することがよくあります。傷んだにおいがする食品への最善の対処法は、捨てることです。

## 寄生虫

寄生虫は、空気、飲料水、食品、直接接触を通じて人体に侵入することがあります。寄生虫が人体の循環系に侵入すると、白血球を攻撃する一方で、肺や肝臓などの臓器に到達したり、血管やリンパ管を詰まらせたりすることがあり、肝硬変、門脈圧亢進症、象皮病などの病気を引き起こします。また、人が有鉤条虫の中間宿主になると、寄生虫が眼球、心臓、脳にまで到達し、命を脅かすこともあります。

以下の食品は、必ず十分に加熱するのが望ましいです。そうしないと、対応する寄生虫が体内に残る可能性があります：

* タニシ：住血線虫
* 刺身：肝吸虫
* タウナギ：顎口虫
* ウシガエル：マンソン裂頭条虫の幼虫
* 豚肉：有鉤条虫
* 牛肉の表面（表面に火が通っていれば食べられます）：無鉤条虫

## 食品の安全な加熱温度

食品を十分な温度まで加熱し、一定時間その温度を保つことで、細菌や寄生虫が生き残るリスクをある程度減らせます。
食品の種類によって必要な温度は異なります。調理する人は、調理用温度計を使って食品の中心温度を測定してください。

温度測定に使うもの：調理用温度計
食品の中心温度を測定する

以下は、業界標準の食品の安全な加熱温度です：

| | 塊肉 | ひき肉 | 丸ごと |
|-----------|------------------------------------------------|-------|-------|
| 豚肉 | 71°C | 71°C | |
| 家禽肉 | 74°C | 74°C | 85°C |
| 牛肉/羊肉 | ミディアムレア（3分焼き）：63°C；ミディアム（5分焼き）：71°C；ミディアムウェル（7分焼き）：77°C | 71°C | |
| 残り物の再加熱 | 74°C | | |

[米国農務省](https://www.usda.gov/about-usda/news/blog/cooking-meat-check-new-recommended-temperatures)の 2011 年の最新基準に基づき、食品の安全な調理温度は以下のように更新されました：

| | 塊肉 | ひき肉 |
|-----------|------------------------------------------------|-------|
| 豚肉 | 63°C（熱源から離した後、3 分間休ませる必要があります） | 71°C |
| 家禽肉 | 74°C | 74°C |
| 牛肉/羊肉 | 63°C（熱源から離した後、3 分間休ませる必要があります） | 71°C |

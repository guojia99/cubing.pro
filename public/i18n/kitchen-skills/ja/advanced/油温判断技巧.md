# 油温の見分け方と主な温度・単位の換算表

* 油温が 120&deg;C-140&deg;C の場合：柔らかく揚げる調理[^1]や、油通しして炒める調理[^2]に適しています。油の入った鍋に箸を入れても、周囲にはほとんど泡が出ず、青い煙も音もなく、油面は穏やかです。
* 油温が 150&deg;C-160&deg;C の場合：調理に最適な温度です。油の入った鍋に箸を入れると、周囲に少し泡が出て、かすかに青い煙が立ち、油が外側から中央に向かって動きます。
* 油温が 160&deg;C-180&deg;C の場合：揚げ色を付け、カリッと揚げるのに適しています。油の入った鍋に箸を入れると、青い煙が大量に立ち上りますが、油面はかえって比較的穏やかです。
* （注）できれば油温測定用の赤外線温度計を購入し、温度計は慎重に使用してください。

> インターネットの料理動画でいう油温の「何割」は、300&deg;C を十割としたときの割合を指します。
> つまり、油温が n 割のとき T_n = 30n ［摂氏度］です。
> 温度の換算式
> C = 5/9 *(F - 32)
> または
> F = 9/5*C + 32

## 油温の対照表

上記の説明を基にした表です。誤差の数値は専門的な測定に基づくものではありません。

| 摂氏 °C | 一般的な呼び方 | 華氏 °F |
| :----: | :----: | :----: |
| -18±4 | 急速冷凍（冷凍） | -0.4±4 |
| 4±2 | 冷蔵保存 | 40±4 |
| 30±10 | 常温 | 86±18 |
| 60±10 | 二割 | 140±18 |
| 90±10 | 三割 | 194±18 |
| 120±10 | 四割 | 248±18 |
| 150±10 | 五割 | 302±18 |
| 180±10 | 六割 | 356±18 |
| 210±10 | 七割 | 410±18 |
| 240±10 | 八割 | 464±18 |
| 270±10 | 九割 | 518±18 |
| 300±10 | 十割 | 572±18 |

* ^1: 柔らかく揚げる調理とは、小さな塊、薄切り、または棒状の食材に衣を付け、油の入った鍋に入れて、七〜八割ほど火が通るまで揚げる方法です。
* ^2: 油通しして炒める調理では、柔らかい肉や魚介などの動物性食材を細切り、薄切り、角切り、棒状などに切り、卵白とでんぷんを薄くまとわせます。低温の油に入れてほぐし、穴あきのざるにあけて余分な油を切ります。

# 點決定食乜嘢

每次煮飯之前，要決定食乜嘢都係我一大難題，所以唯有用數學嚟描述一下。

## 計法

### 計算肉類餸同素菜嘅數量

* 餸嘅數量 = 人數 + 1。
* 肉類餸比素菜多一個，或者一樣多就得。

咁就計到肉類餸同素菜各要幾多個，再喺上一步嘅食譜入面揀就得。

#### 用形式語言描述

當有 `N` 個人嗰陣，
設`素菜數量`為 `a`，`肉類餸數量`為 `b`。
`N`、`a`、`b` 都係整數。

呢個時候有以下不等式組：

* a + b = N + 1
* a ≤ b ≤ a+1

解出嚟就係：

```javascript
const a = Math.floor((N+1)/2);
const b = Math.ceil((N+1)/2);
```

### 點揀餸

* 如果超過 8 個人食飯，可以考慮喺肉類餸入面加一道魚。
* 如果有小朋友，可以考慮加啲帶甜味嘅餸。
* 可以考慮加特色餸、拿手餸。
* 揀肉類餸嗰陣，留意唔好全部都用同一種動物嘅肉。可以依次考慮：`豬肉`、`雞肉`、`牛肉`、`羊肉`、`鴨肉`、`魚肉`。
* 唔好揀奇奇怪怪嘅動物嚟做肉類餸。

如果仲係決定唔到，可以用 [今日食乜嘢？](https://github.com/ryanuo/whatToEat) 呢個工具幫你揀今日食乜嘢。

# 點樣洗碗

## 21世紀嘅洗碗

洗碗睇落係廚房工作入面最簡單嘅一樣。隨住現代廚房工具愈嚟愈複雜，「洗碗」早就唔止字面上咁簡單，但好多人對洗碗嘅認識仍然停留喺「用毛巾擦洗碗碟」嘅「古法」階段，有啲家庭甚至因為長期用唔科學嘅方法洗碗，埋下健康隱患（例如致癌物）。為咗等大家掌握科學、高效、現代化嘅洗碗方法，呢份指南會詳細介紹洗碗嘅流程、注意事項，同埋整理要避開嘅陷阱。

## 洗碗嘅目的

無論你用傳統手洗定洗碗碟機，最終目的都得一個：令餐具回復到**可以安全再次使用**嘅狀態。具體嚟講，要同時做到以下幾點：

1. **睇落乾淨**：表面冇油膜、水漬、餸渣、指紋。
2. **摸落乾淨**：用手指輕輕掃過碗底、匙羹柄、杯口內側，冇黏笠感就代表乾淨。
3. **聞落乾淨**：冇油脂酸敗嘅味道，亦冇刺鼻嘅洗潔精味。
4. **乾爽可用**：瀝乾或者抹乾之後冇明顯積水，收埋嗰陣唔會濕漉漉。
5. **冇交叉污染**：處理過生肉嘅工具冇污染已經洗乾淨嘅餐具。

以上 5 點全部做到，先算洗乾淨。

## 要準備嘅工具

現代廚房嘅餐具用料好多樣（易潔塗層、鑄鐵、搪瓷、木、不鏽鋼……），唔同物料要用唔同清潔工具，揀錯工具本身就係一個常見陷阱。「廚房準備」入面已經預設有洗滌相關工具，洗碗嗰陣建議確保以下物品用得着：

```text
熱水（優先）、凍水、洗碗槽、洗碗盆（可選）、洗碗海綿或百潔布
洗潔精、鋼絲刷（只限不鏽鋼鍋具，唔可以用喺易潔鑊或塗層表面）
瀝水架、乾淨抹布或者廚房紙、手套（可選）
洗碗碟機（可選，詳見後文）
```

### 工具使用要點

- **海綿／百潔布**：日常洗碗碟嘅首選。用完要揸乾，放喺通風處晾乾，避免海綿本身發霉發臭。
- **鋼絲刷球**：只可以用喺鐵鑊、不鏽鋼煲等堅硬、冇塗層嘅表面。**禁止**用喺易潔鑊、陶瓷塗層、精緻瓷器上，否則會破壞塗層。
- **抹布**：抹乾餐具嘅抹布一定要同抹爐頭、抹地嘅抹布分開，撈亂用就等於白洗。
- **洗碗碟機**：如果有洗碗碟機，可以跳過手洗嘅主要流程，但仍然要先刮走食物殘渣，洗完再收好。詳見後面「洗碗碟機」部分。

## 整體流程

好多人洗碗得「落洗潔精→沖水」兩步，咁樣遠遠唔夠。一套科學嘅洗碗流程應該包括以下環節：

```text
收集分類 → 刮走餸渣同浸泡 → 清洗去污 → 沖走洗潔精 → 檢查 → 整乾 → 收納
```

每一步都有不可取代嘅作用，跳過任何一步都可能留下隱患。下面逐步講解。

## 詳細步驟

### 1. 收集同分類

食完飯先將散落各處嘅碗、碟、筷子、匙羹、煲鑊、砧板等集中喺鋅盆旁邊，按污糟程度排好次序。

建議按以下次序清洗（由輕到重）：

1. **輕微污漬**：玻璃杯、水杯、筷子、匙羹
2. **中度污漬**：餸碟、飯碗
3. **嚴重污漬**：炒鑊、炸嘢用嘅煲鑊、焗盤、黐咗蛋液嘅容器
4. **高風險**：處理過生肉、生魚嘅砧板同刀具（建議最後分開處理）

點解要分類：先洗冇咁污糟嘅，水同海綿都比較乾淨，唔會將厚重油污帶到杯上；處理生食嘅工具最後分開洗，避免將病原體帶到已經洗乾淨嘅餐具上。

### 2. 刮渣同浸泡

呢一步好多人都會跳過，但佢會直接影響之後有幾難洗。預先處理好頑固殘渣，正式洗嗰陣就唔使反覆刷，既慳力又慳水。

做法：

1. 用餐巾紙或者鑊鏟刮走大塊殘渣，倒入廚餘垃圾桶。**唔好直接沖落去水渠**，好容易塞渠。
2. 以下情況需要浸泡：
   - 乾硬咗嘅飯粒、澱粉糊
   - 凝固咗嘅蛋白質（蛋液、牛奶殘留物）
   - 燒燶咗嘅煲鑊、黐底燶漬
3. 浸泡方法：
   - **一般油污、飯粒**：用熱水浸 5–15 分鐘
   - **燒燶嘅煲底**：用熱水 + 少量洗潔精浸泡，或者先加水煲滾，再熄火焗 10–20 分鐘
   - **不鏽鋼上嘅茶漬、水垢**：可以用少量白醋浸過再刷洗（唔好同漂白類產品混用）

> [!Warning]
> **油鑊未冷卻嗰陣，唔好直接沖凍水**。熱脹冷縮可能令鑊身變形，油遇到凍水亦可能濺起，令人燙傷。
> **鑄鐵鑊、碳鋼鑊**唔好長時間浸泡，否則容易生鏽。洗完應該即刻抹乾，再薄薄搽一層油。

### 3. 清洗：去油去污

呢個係成個流程嘅核心步驟。建議水溫由暖水至熱水（約 40–50°C），熱水可以有效降低油脂黏度，大幅提升去污效率。如果屋企水龍頭可以調校水溫，建議直接調到合適溫度。

標準手洗步驟：

1. 開水龍頭，或者喺洗碗盆準備一盆暖水。
2. 喺海綿上唧少量洗潔精（綠豆至黃豆咁大粒，約 1–2ml 就夠），搓起泡。
3. 按「外→內、柄→頭、邊緣→中心」嘅次序刷洗：
   - **碗**：先刷外壁，再刷內壁，重點刷碗底內側
   - **碟**：碟面、碟邊、碟底
   - **筷子同匙羹**：筷子頭同匙羹頭係重點污糟位置
   - **煲鑊**：底部、內壁、邊緣，唔好唔記得外側濺到嘅油漬
4. 遇到頑固污漬，先用海綿粗糙嗰面喺污漬位置加力擦洗，唔好一開始就用鋼絲刷球。
5. 砧板同刀具：
   - 生肉砧板：用洗潔精刷洗之後，可以用熱水燙洗。情況許可嘅話，定期消毒。
   - 刀具：刷洗嗰陣刀鋒要向住遠離自己嘅方向，避免割傷。

洗潔精唔係落得愈多就愈乾淨。用得太多只會令之後過水更費工夫，而且殘留喺餐具上本身都唔好。

### 4. 過水：沖走洗潔精

清洗之後，要用清水將洗潔精同已經溶解嘅污垢徹底沖走。

做法：

1. 用流動清水徹底沖洗每件餐具，直到符合以下條件：
   - 冇泡沫
   - 手指摸落冇滑潺潺嘅感覺
   - 表面水膜均勻（如果油未洗乾淨，水會聚成一粒粒水珠，唔會均勻攤開）
2. 杯口、碗底凹槽、煲柄接縫位容易殘留洗潔精，要沖多幾秒。
3. 如果用洗碗盆盛水過水，建議最少換一次水，最後再用流動水沖一次。

### 5. 檢查

每件餐具都檢查一次：

- **睇**：對住光睇吓有冇油膜反光
- **摸**：用指腹輕輕摸內壁，睇吓有冇黏笠感
- **聞**：湊近聞吓有冇酸味或者洗潔精味

唔合格嘅，就返去第 3 步，針對污漬位置再洗。唔好仲有未洗乾淨嘅地方就直接拎去晾乾。

### 6. 弄乾

洗乾淨唔代表可以直接用，因為潮濕環境係細菌繁殖嘅溫床。好多人洗完碗就覺得做完，但如果未乾就收埋，之前嘅心機可能白費。

可以揀以下做法：

| 做法 | 具體步驟 | 適用情況 |
| --- | --- | --- |
| 瀝乾 | 倒轉擺喺瀝水架上，自然風乾 | 日常最常用，慳力 |
| 抹乾 | 用乾淨嘅專用抹布抹到冇明顯水珠 | 趕住收埋、避免玻璃杯留低水漬 |
| 熱風烘乾 | 用洗碗碟機嘅烘乾模式或者暖風 | 一次過處理大批餐具 |

注意：

- 瀝水嗰陣盡量**倒轉或者側住擺**，避免碗碟凹位積水。
- 如果抹布本身已經有異味，或者濕漉漉又黏笠笠，就先洗乾淨塊抹布，再用嚟抹餐具。
- 唔好用啱啱抹過爐頭嘅布嚟抹碗。

### 7. 收納

確認餐具已經乾爽之後，放返入廚櫃或者碗架。

幾條基本規則：

1. **未乾唔收**：潮濕嘅餐具放入櫃會滋生細菌同異味。
2. 疊起碗碟之前，確認底部乾淨，唔好將污糟嘅碗底壓喺下面隻碗嘅內壁上。
3. 筷子、匙羹、叉嘅頭向上擺，或者按屋企瀝水籃設計嘅方向擺，保持通風。
4. 處理過生食嘅刀具同砧板，要同日常餐具分區存放。

## 建議清洗次序

如果一次過洗晒成套餐具，建議按以下次序：

```text
1. 玻璃杯同其他杯
2. 筷子、匙羹、叉
3. 碟同碗
4. 鑊鏟、湯殼等煮食工具
5. 多油嘅鑊同煮食鍋
6. 生食砧板同刀具（最後先洗，之後另外洗乾淨水槽）
7. 沖洗水槽同水龍頭手柄，做埋收尾
```

道理係：由污糟程度低嘅洗到高嘅，避免後面嘅厚重油污反過來整污糟前面已經洗好嘅嘢。

## 唔同物料餐具嘅處理方法

現代廚房通常都會混合使用各種物料嘅煲鑊同餐具，但唔同物料嘅清洗方法可以差好遠。用錯方法，輕則損壞用具，重則帶嚟健康隱患。

### 易潔鑊

- 用海綿軟面 + 中性洗潔精，輕手擦洗就得。
- **禁止用鋼絲刷球、硬鑊鏟刮塗層**，否則會破壞塗層，隻鑊亦會報銷。
- 洗完抹乾，避免長時間積水。

### 鑄鐵鑊 / 碳鋼鑊

- 盡量唔用或者少用洗潔精，保護鑊面嘅油膜。
- 用熱水 + 刷清走殘渣就得。
- 洗完抹乾，用細火烘乾，再薄薄搽一層食油防鏽。

### 木砧板 / 木鑊鏟

- 快手洗，唔好長時間浸泡，否則木會爆裂變形。
- 洗完企起晾乾。
- 可以定期搽食油保養（砧板）。

### 筷子

- 重點洗接觸食物嗰端（筷子頭）。
- 竹筷子同木筷子容易積水爆裂，洗完一定要晾乾。
- 如果嚴重發霉或者爆裂，就直接換新，唔好勉強繼續用。

### 洗碗碟機

洗碗碟機係現代廚房入面最能夠提升效率嘅工具之一，但佢唔係「啲碗掟入去就得」嘅萬能機，仍然要人手配合，先可以發揮最好效果：

1. 先刮走大塊殘渣（骨頭、菜葉等），否則容易塞住濾網同噴水孔。
2. 按洗碗碟機說明書擺好餐具，碗口向下、碟側住擺，留意唔好阻住噴水臂轉動。
3. 揀合適程序：厚重油污用強力或者高溫模式，日常輕微污漬用快洗或者節能模式就夠。
4. 洗完打開檢查，重點睇碗底凹槽同杯口內側，有未洗乾淨嘅地方，就用手補洗。
5. 定期清理洗碗碟機濾網同密封膠圈，防止異味同發霉。建議每 1–2 星期清理濾網，每個月用專用清潔劑空機洗一次。

### 氣炸鍋

氣炸鍋嘅炸籃同底盤係主要清洗部件，好多人只係抹一抹就放返入去，日子耐咗油垢會碳化，影響加熱效果同食物安全。

- 每次用完，等部機冷卻之後拎出炸籃同底盤，用暖水 + 洗潔精 + 海綿清洗。
- 炸籃網格嘅罅隙容易卡住食物殘渣，可以用舊牙刷或者細刷幫手清理。
- **唔好用鋼絲刷球刷炸籃**，大部分炸籃都有易潔塗層，用鋼絲刷球會破壞塗層，令之後使用時黐底同塗層剝落。
- 機身內壁如果濺到油污，用濕抹布抹就得，**唔好將成個機身浸入水**。
- 發熱管（頂部）如果有油漬，等冷卻之後用濕布輕輕抹。長期唔清理嘅油漬喺高溫下會出煙，甚至產生有害物質。

### 電飯煲

電飯煲內膽大多有易潔塗層，清洗嗰陣要小心保護塗層。好多人都忽略咗清洗蒸氣閥同煲蓋內側。

- 內膽用海綿軟面 + 洗潔精清洗，**禁止用鋼絲刷球**。塗層一旦刮損剝落，煮飯就會黐底，甩出嚟嘅塗層碎片亦會混入食物。
- 煲蓋內側、蒸氣孔、密封膠圈都係容易忽略嘅位置，帶有澱粉嘅蒸氣會喺呢啲地方凝結成黏糊糊嘅殘留物，耐咗就會發酸發臭。建議每次用完抹乾淨煲蓋內側，定期拆低密封膠圈清洗。
- 煲身外殼只可以用濕布抹，**唔好浸水**，避免損壞電路。

### 壓力煲 / 電壓力煲

壓力煲嘅清洗重點唔喺煲身本身，而係密封膠圈、排氣閥同煲蓋等關乎安全嘅部件。呢啲部件如果洗得唔夠乾淨，除咗影響衞生，仲可能影響密封性能，帶嚟安全隱患。

- **密封膠圈**：每次用完拆低，用暖水 + 洗潔精清洗。膠圈凹槽容易藏住食物殘渣同油垢，要仔細擦洗。洗完晾乾先裝返。膠圈老化（變硬、變形、有裂紋）之後要及時更換。
- **排氣閥 / 限壓閥**：拆低之後用清水沖洗，確保閥孔暢通冇塞住。如果閥孔畀食物殘渣塞住，下次用嗰陣可能會令洩壓出現異常。
- **煲蓋**：內側同煲蓋邊緣凹槽容易積埋油污同食物殘留物，要擦洗乾淨。
- **內膽**：清洗方法同普通不鏽鋼煲或者易潔煲一樣，按內膽物料揀工具。

### 焗爐

焗爐嘅焗盤、焗架同內壁都要定期清洗。好多人只洗焗盤，忽略咗焗架同內壁，日子耐咗油垢碳化就會產生煙味，甚至影響食物風味。

- **焗盤**：趁仲暖嗰陣（小心唔好燙親手）用洗潔精 + 海綿清洗，冷卻之後油垢會凝固，變得難清理。有頑固燒結物嘅話，用熱水浸 15–30 分鐘再刷。鋪錫紙或者烘焙紙，可以令焗盤易洗好多。
- **焗架**：網格狀焗架嘅罅隙最難洗，可以放入鋅盆，用熱水 + 洗潔精浸過再用刷刷洗。
- **內壁**：冷卻之後用濕布 + 少量洗潔精抹。如果油漬已經碳化變黑，可以用梳打粉 + 水開成糊，搽喺污漬上，擺 1–2 小時再抹。唔好用鋼絲刷球刮焗爐內壁，容易刮損表面塗層。
- 有啲焗爐有自動清潔功能（高溫熱解），可以按說明書使用，但用完仍然要抹走剩低嘅灰燼。

### 微波爐

微波爐內壁同轉盤容易畀食物濺出嚟嘅湯汁、油脂整污糟，好多人都唔清理，耐咗就會有異味，加熱嗰陣舊食物殘渣仲會反覆受熱，產生燶味。

- **轉盤**：拎出嚟，當普通玻璃／瓷器咁洗就得。
- **內壁**：用濕布 + 少量洗潔精抹。如果有濺出嚟又乾硬咗嘅食物，可以喺微波爐放一碗水，加幾片檸檬，用中火加熱 3–5 分鐘，等蒸氣軟化污漬再抹，會輕鬆好多。
- **爐門密封膠邊**：門框邊緣嘅密封膠邊係容易忽略嘅死角，油漬同碎屑會積喺罅隙入面，要定期用濕布抹。
- **唔好用含金屬嘅清潔工具**抹微波爐內壁，以免刮損內壁塗層。

### 蒸鍋 / 蒸格

蒸鍋同蒸格用完之後，最常見嘅問題係水垢同澱粉殘留物。

- **不鏽鋼蒸格**：用洗潔精 + 海綿正常清洗就得。蒸格啲窿容易卡住麵食殘渣（例如饅頭、包嘅底部），要及時清理，否則乾硬咗就好難清走。
- **竹蒸籠**：唔好用洗潔精，用熱水 + 刷刷洗就得。竹會吸住洗潔精嘅味道，下次蒸嘢嗰陣，啲味會滲入食物。洗完一定要放喺通風處晾乾，否則容易發霉。發霉嘅竹蒸籠應該掉咗佢。
- **蒸鍋鍋身**：底部容易積水垢（白色結晶），可以用白醋浸 10–20 分鐘再刷洗。

### 鑊鏟 / 湯勺 / 笊籬

呢啲工具日日都用，但唔同物料嘅清洗方法有分別：

- **不鏽鋼**：最襟用，可以用鋼絲刷球刷，唔怕刮花。留意清洗勺柄接駁位嘅罅隙，油污好容易藏喺嗰度。
- **矽膠**：用海綿 + 洗潔精清洗就得。矽膠耐高溫，但容易吸色同吸味（尤其係咖喱、茄汁），如果變色嚴重，可以用梳打粉水浸泡。唔好用鋼絲刷球刷矽膠表面，會刮花，令污垢更容易藏住。
- **木**：同木鑊鏟、木砧板一樣，快洗快乾，唔好浸泡。詳見前面「木砧板 / 木鑊鏟」部分。

### 刨皮刀

刨皮刀刀鋒同卡槽之間嘅罅隙好細，蔬菜皮纖維同澱粉好容易卡喺入面。好多人用完只係喺水下面沖一沖，其實未洗乾淨。

- 用舊牙刷順住刀鋒方向刷洗罅隙（留意方向，避免割傷）。
- 洗完揈走水分，放喺通風處晾乾。不鏽鋼刨皮刀如果長期潮濕又唔晾乾，刀鋒一樣會生鏽變鈍。

### 水煲 / 電熱水煲

水煲嘅主要問題唔係油污，而係水垢。

- **清除水垢**：倒入白醋或者檸檬酸（約 1–2 湯匙），加滿水，煲滾之後熄火浸 30–60 分鐘，倒走之後用清水沖洗 2–3 次。水質比較硬嘅地區，建議每 1–2 星期除一次水垢。
- 唔好用鋼絲刷球刷水煲內壁，容易刮花不鏽鋼表面，刮痕會令水垢更容易黐住。
- 煲嘴同煲蓋內側都會積水垢，記得一齊清理。

## 常見問題同陷阱

以下係洗碗過程入面最常見嘅錯誤做法同觀念，按類型整理。每一項都有講明具體後果，知道「點解唔可以咁做」，先可以真正避開呢啲陷阱。

### 清洗習慣

- **淨係沖，唔擦洗**：單靠水沖係沖唔走油膜嘅。油脂唔溶於水，一定要靠洗潔精入面嘅表面活性劑乳化油脂，再配合海綿摩擦先清得走。淨沖唔擦洗嘅結果，就係碗面睇落乾淨，實際上仲有一層薄油膜，摸落滑潺潺，下次裝飯嗰陣，食物就會沾上變壞油脂嘅異味。
- **落太多洗潔精**：泡沫多唔代表洗得乾淨，洗潔精超過一定濃度之後，去污效果唔會再提升。落太多嘅後果係過水嗰陣好難沖乾淨，殘留嘅洗潔精會喺下次食飯嗰陣一齊食落肚。長期攝入洗潔精殘留物雖然唔會即刻中毒，但會刺激腸胃黏膜，亦冇必要冒呢個風險。
- **只洗內壁，唔洗外壁同底部**：好多人洗碗只刷入面，忽略咗外壁同碗底。疊起碗碟嗰陣，上面隻碗嘅底會直接掂到下面隻碗嘅內壁，如果底部污糟，就等於下面隻碗白洗。
- **未沖乾淨就晾乾**：碗上仲有洗潔精泡沫就拎去瀝水。晾乾之後，洗潔精會喺碗面形成一層乾咗嘅薄膜，下次用嗰陣跟住食物入肚。判斷方法好簡單：用手指摸一摸，如果仲有滑潺潺嘅感覺，就代表未沖乾淨。
- **擺過夜唔處理**：澱粉同蛋白質殘渣喺室溫擺一晚，會乾硬到黐得實一實，第二日要花幾倍力氣先刷得甩。更重要嘅係，夏天室溫下，食物殘渣擺 2–4 小時就開始大量滋生細菌，擺過夜嘅污糟碗基本上就係一個培養皿。如果碗入面有肉類殘渣，仲會惹曱甴同果蠅。

### 工具使用

- **用鋼絲刷球刷易潔鑊**：鋼絲刷球會刮損易潔塗層（通常係鐵氟龍），塗層一旦破損就會不斷剝落。破損嘅易潔鑊除咗失去唔黐底嘅功能，甩出嚟嘅塗層碎片仲會混入食物。塗層破損後，鑊身直接外露，亦容易黐底燒燶。正確做法係只用海綿軟面擦洗易潔鑊。
- **用污糟抹布或者臭海綿抹碗**：海綿同抹布長期濕住又唔晾乾，本身就係細菌同霉菌嘅溫床。用發臭嘅海綿去「洗」碗，等於喺碗上搽一層細菌。抹布都一樣，用啱啱抹過爐頭油污嘅布去抹碗，只係將污糟嘢搬咗個位。建議海綿每次用完都揸乾，放喺通風處，抹布就定期高溫清洗或者更換。
- **用硬工具刮搪瓷／陶瓷塗層**：搪瓷煲同有陶瓷塗層嘅煲鑊，表面比較脆弱，用金屬鑊鏟或者鋼絲刷球大力刮，會崩瓷或者刮花。搪瓷崩咗之後露出底層金屬，除咗影響受熱均勻度，外露金屬亦容易生鏽。
- **洗碗全程開大水**：由頭到尾開住水龍頭沖，洗一次碗可能就嘥咗幾十公升水。更好嘅做法係：先閂水，用海綿同洗潔精擦洗晒所有餐具，再一次過開水過水。

### 物料損傷

- **鑄鐵鑊／碳鋼鑊長時間浸泡**：鑄鐵同碳鋼冇防鏽塗層（或者靠一層油膜防鏽），長時間浸喺水入面會好快生鏽。一旦生鏽，除咗唔好睇，鏽蝕嚴重嗰陣仲要重新開鑊養鑊。正確做法係洗完即刻抹乾，用細火烘乾，再薄薄搽一層食油。
- **鑄鐵鑊／碳鋼鑊用大量洗潔精**：洗潔精會洗走鑊面好唔容易先養出嚟嘅油膜，下次用就會嚴重黐底。鑄鐵鑊同碳鋼鑊日常清洗只需要熱水 + 刷，頑固殘渣可以加粗鹽擦走。
- **熱鑊直接沖凍水**：炒完餸嘅鑊溫度好高，直接沖凍水會造成劇烈熱脹冷縮。不鏽鋼鑊可能變形，鑄鐵鑊甚至可能爆裂。鑊入面仲有熱油嗰陣沖凍水，仲會令油水濺起，可能燙傷。應該等隻鑊稍為冷卻先洗。
- **木砧板／木鑊鏟長時間浸水**：木吸水之後會脹，晾乾之後又縮，重複幾次就會爆裂變形。木砧板有裂縫之後，罅隙容易藏住食物殘渣同細菌，好難洗乾淨。正確做法係快洗快乾，企起晾乾。

### 衞生隱患

- **濕碗直接放入櫃**：未晾乾就放入密閉廚櫃，等於畀細菌同霉菌一個溫暖潮濕嘅理想環境。幾日之後，碗上可能有霉點或者異味，成個櫃入面嘅餐具都可能受影響。
- **生熟工具撈埋一齊洗**：切過生肉、生魚嘅砧板同刀具，如果直接放入洗碗水，同其他碗筷一齊洗，生肉可能帶住嘅沙門氏菌、大腸桿菌等，就會經水傳播到其他餐具。正確做法係處理生食嘅工具最後分開洗，有需要就用熱水燙洗或者消毒。
- **瀝水架長期唔清理**：瀝水架底下嘅接水盤，如果唔定期倒水同清洗，積水會發臭、發霉，架上瀝緊水嘅碗反而會畀底部蒸發上嚟嘅污水再次污染。建議每星期清洗一次瀝水架同接水盤。
- **筷子筒底部積水**：筷子頭向下插喺筷子筒入面，如果筒底冇去水孔，或者長期唔清理，底部就會積水發霉。筷子頭係接觸食物嘅部分，浸喺污水入面，就等於每次食飯都用發霉筷子。可以揀有去水孔嘅筷子筒，或者將筷子頭向上擺。
- **竹木筷子發霉仲繼續用**：竹木筷子出現黑色霉斑之後，霉菌已經深入木纖維，一般清洗清唔走。部分霉菌（例如黃曲霉）會產生強致癌物質。發霉、爆裂嘅竹木筷子應該直接掉咗換新。

### 其他容易忽略嘅陷阱

- **唔刮走殘渣就放入洗碗碟機**：以為洗碗碟機乜都洗得。大塊殘渣（骨頭、菜葉、飯粒）會塞住濾網同噴水孔，令洗碗碟機清洗效果變差，嚴重嗰陣仲會損壞排水泵。放入洗碗碟機之前，最少要先刮走明顯嘅固體殘渣。
- **洗碗碟機長期唔清理**：洗碗碟機入面嘅濾網、密封膠圈、噴水臂如果長期唔清理，會積埋油污同霉菌，除咗洗出嚟嘅碗有異味，仲可能令洗碗碟機本身變成污染源。建議每 1–2 星期清理一次濾網，每個月用洗碗碟機專用清潔劑行一次空機清洗程序。
- **殘渣直接沖落去水渠**：飯粒、麵條、菜葉等澱粉類殘渣沖落去水渠之後，容易發脹結成一團，耐咗就會塞渠。油脂沖入去之後會喺渠壁凝結，加快堵塞。正確做法係先將固體殘渣刮入垃圾桶，鋅盆去水口加個濾網，隔住漏網嘅碎渣。
- **洗潔精同含氯漂白水混用**：有啲人會喺洗碗水同時加洗潔精同 84 消毒液（含氯漂白劑），諗住「雙重殺菌」，但兩者混合可能產生有害氣體，刺激呼吸道。如果需要消毒，應該先正常清洗、過水，再分開用消毒液浸泡，最後用清水沖乾淨。

## 小結

煮飯係將食材變成食得嘅狀態，洗碗就係令廚房回復到可以再次煮飯嘅狀態。兩件事形成一個完整循環，只煮飯唔洗碗，個廚房好快就用唔到。

掌握科學嘅洗碗方法、善用現代廚房工具、了解唔同物料嘅正確處理方法，就可以令洗碗變得又有效率又安全。養成「用完就洗、洗完就收」嘅習慣，先可以長久煮飯落去。

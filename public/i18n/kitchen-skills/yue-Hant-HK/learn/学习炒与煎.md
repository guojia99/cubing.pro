
# 炒／煎

## 器具

可以用普通金屬製（鐵／不鏽鋼／鋁）炒鑊、煎鑊，或者易潔鑊。

唔建議用鋁製容器，原因請睇食物安全一節

### 注意事項

* 用普通鑊炒餸而唔黐底嘅方法：

#### 先炒蛋法

* 無論炒咩餸，之前都先炒隻蛋，炒完唔好洗鑊，再炒下一道餸時就唔會黐底。

#### 熱鑊凍油法

* 記住一定要熱鑊凍油，首先燒熱隻鑊
  * 乾淨嘅鑊乜都唔放，空鑊燒熱，令佢受熱均勻
  * 倒入凍油，轉動隻鑊，令油沾勻成隻鑊（可以來回轉動，令佢受熱均勻）
  * 見到有氣由鑊入面冒出，就代表鑊入面嘅油已經燒熱
  * 將油倒出，倒完唔好洗鑊
  * 可以重複以上步驟 2-3 次，令唔黐底嘅效果更好
  * 注意：如果用煤氣爐或者石油氣爐，可能會搶火，請小心

#### 熱鑊雙油法

* 首先燒熱隻鑊
  * 乾淨嘅鑊乜都唔放，空鑊燒熱，令佢受熱均勻
  * 倒入「少量凍油」，轉動隻鑊，令油沾勻成隻鑊（可以來回轉動，令佢受熱均勻）
  * 見到有氣由鑊入面冒出，就代表鑊入面嘅油已經燒熱
  * 再繼續倒入凍油，開始炒餸
  * 注意：如果用煤氣爐或者石油氣爐，可能會搶火，請小心。

補充：

* 目的係令鑊底沾滿油，市面上所有家用鑊都適用，掛好油就即刻變成易潔鑊。
* 用易潔鑊煎炒食物唔會黐底。易潔鑊嘅功能來自內壁嘅塗層。**金屬鑊鏟會刮花塗層。用易潔鑊時，應該用木製或者矽膠鑊鏟，避免整壞塗層。**

### 流程

開火 → 將鑊平放喺爐火上，燒熱 → 倒油入鑊，燒熱 → 放入食材，翻炒 → 起鑊之前記得落調味料

### 注意事項

* 想知道鑊／油夠唔夠熱，可以將手平放喺鑊上方感受熱力；油熱咗先可以放食材。
* 倒油入鑊之前，一定要確認鑊入面冇殘留水分。**水會令熱油四濺，造成危險。**
* 承上，食材落油鑊之前應該瀝乾水分（蛋漿冇問題）；同樣道理，唔可以將未解凍嘅食材放入油鑊，以免冰融化後造成危險。
* **如果油鑊着火，千祈唔好倒水救火**，咁樣會令火勢更大。啱啱起火時，可以即刻熄火，再冚上鑊蓋。

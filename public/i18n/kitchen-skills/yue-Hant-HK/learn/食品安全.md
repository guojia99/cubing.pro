# 食物安全

## 中毒

以下食物有引致中毒嘅風險：

* 未成熟嘅青番茄
* 未煮熟透嘅四季豆（芸豆）、豆角（豇豆）、[白刀豆](https://zh.wikipedia.org/wiki/%E7%99%BD%E5%88%80%E8%B1%86)
* 發芽嘅薯仔（山藥）、番薯（紅薯）、花生
* 處理唔正確/未煮熟透嘅[金針菜](https://zh.m.wikipedia.org/wiki/%E9%BB%84%E8%8A%B1%E8%8F%9C)，可以引致[秋水仙鹼](https://zh.m.wikipedia.org/wiki/%E7%A7%8B%E6%B0%B4%E4%BB%99%E7%B4%A0)中毒。
* 生豆漿
* 浸發得太耐嘅木耳（唔單止木耳，所有菇菌浸發得太耐都有中毒風險）
* 未煮熟嘅動物內臟
* 唔認識嘅菇，或者未煮熟嘅菇（有句俗語話：「紅傘傘，白柄柄，食完一齊瞓棺材板。」一般嚟講，菇越靚就越危險。）
* ……（歡迎補充）

酸性食物長時間放喺鋁製容器儲存同烹煮，一樣有引致中毒嘅風險，例如：

* 酸菜
* 筍乾
* 茄醬
* 檸檬汁
* 滷肉
* 豉油同醬菜

## 敏感

以下係常見會引起敏感嘅食物（注意：敏感反應一般會跟一世）：

成人：

* 蝦、蟹、貝殼類海鮮（食咗唔新鮮、因而滋生細菌嘅海鮮）
* 花生
* 果仁
* 魚類

小朋友：

* 花生
* 果仁
* 蛋類
* 牛奶（主要係對牛奶入面嘅 A1 蛋白唔耐受）
* 小麥同大豆

## 沙門氏菌感染

沙門氏菌比較常見於動物來源嘅食物；蔬菜亦可能因為受糞便污染，而帶有沙門氏菌。

以下食物有引致沙門氏菌感染嘅風險：

* 未完全煮熟嘅蛋
* 未完全煮熟嘅肉
* 未經殺菌嘅奶

## 黃曲霉毒素

黃曲霉毒素通常係由黃曲霉、寄生曲霉同另外幾種霉菌，喺發霉穀物入面產生，例如米、豆類、花生等，係至今最強嘅致癌物質。要加熱到 280℃ 以上先開始分解，所以一般加熱唔容易破壞佢嘅結構。

以下食物有引致黃曲霉毒素中毒嘅風險：

* 變壞嘅花生
* 變壞嘅米
* 變壞嘅粟米

留意，以上食物亦包括用佢哋製成嘅食品，例如米粉、粟米粉；經安全培育生產嘅花生苗（發芽花生），可以視為安全食用。

## 3-硝基丙酸

3-硝基丙酸由蔗生節菱孢菌產生，呢種真菌常見寄生喺甘蔗同椰子入面。中毒主要會損害中樞神經系統。急性期症狀包括嘔吐、暈眩、陣發性抽搐、眼球凝視一側、昏迷，甚至死亡。後遺症主要係錐體外系受損，主要症狀包括屈曲、扭轉、痙攣、四肢僵硬，同埋靜止時肌張力降低等。暫時未有針對呢種毒素嘅特效解毒藥。

以下食物有引致 3-硝基丙酸中毒嘅風險：

* 紅心甘蔗
* [變壞嘅椰子](https://www.bilibili.com/video/BV1w84y147TU)

除咗睇外觀判斷，氣味亦係重要嘅判斷標準。變壞嘅植物往往會散發特別氣味（例如酒糟味、酸味等）。聞落有腐壞味嘅食物，最好嘅處理方法就係掉咗佢。

## 寄生蟲

寄生蟲可以經空氣、飲用水、食物同直接接觸進入人體。如果寄生蟲進入人體循環系統，一方面可以攻擊白血球，另一方面可以去到肺、肝等內臟，或者塞住血管、淋巴管，引起肝硬化、門脈高壓、象皮病等疾病。如果人係豬肉絛蟲嘅中間宿主，寄生蟲甚至會去到眼球、心臟同大腦，危及生命。

以下食物最好確保完全煮熟，否則可能會喺體內留下相應嘅寄生蟲：

* 田螺：管圓線蟲
* 刺身：肝吸蟲
* 黃鱔：顎口線蟲
* 牛蛙：曼氏裂頭蚴寄生蟲
* 豬肉：豬肉絛蟲
* 牛肉表面（只要表面熟咗就食得）：牛肉絛蟲

## 食物安全溫度

用足夠高嘅溫度加熱食物，並維持一段時間，可以喺一定程度上降低細菌同寄生蟲存活嘅風險。
唔同食物有唔同溫度要求，煮食嗰陣應該用廚房溫度計量度食物中心溫度。

量度溫度應該用：廚房溫度計
量度食物中心溫度

以下係業界標準嘅食物安全溫度：

|           | 原塊                                            | 碎肉  | 原隻  |
|-----------|------------------------------------------------|-------|-------|
| 豬肉      | 71°C                                           | 71°C  |       |
| 禽肉      | 74°C                                           | 74°C  | 85°C  |
| 牛肉/羊肉 | 3 成熟：63°C；5 成熟：71°C；7 成熟：77°C         | 71°C  |       |
| 翻熱剩餸 | 74°C                                           |       |       |

根據[美國農業部](https://www.usda.gov/about-usda/news/blog/cooking-meat-check-new-recommended-temperatures)2011 年最新標準，食物安全烹調溫度已更新如下：

|           | 原塊                                            | 碎肉  |
|-----------|------------------------------------------------|-------|
| 豬肉      | 63°C（離開熱源後要靜置 3 分鐘）                 | 71°C  |
| 禽肉      | 74°C                                           | 74°C  |
| 牛肉/羊肉 | 63°C（離開熱源後要靜置 3 分鐘）                 | 71°C  |

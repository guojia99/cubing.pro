# 學用刀

呢份用刀教學係寫畀家庭廚房新手嘅。目標係切得穩陣、大小啱用、乾淨安全，唔使追求速度。先睇安全須知同握刀方法，再揀需要處理嘅食材；遇到硬骨、堅硬外殼，或者凍到硬晒嘅食物，就換工具，或者買已經處理好嘅食材。

## 開始之前：先準備好廚房

1. 保持枱面光線充足、乾淨，騰出足夠空間；小朋友同寵物要遠離操作範圍。攰、飲過酒，或者精神唔集中嗰陣，暫時唔好用刀。
2. 洗乾淨雙手，再抹乾。檢查刀柄有冇鬆、刀刃有冇崩口，發現損壞就停用。隻手有油或者濕滑時，唔可以直接握刀。
3. 揀完整、平坦嘅木砧板，或者適合接觸食物嘅膠砧板。砧板底墊防滑墊，或者扭乾嘅濕布，再用手推一推，確認唔會跣。唔好喺玻璃、石材或者瓷碟上切嘢。
4. 擺好待切食材、裝切好食材嘅碗，同裝廢料嘅碗，砧板前沿唔好伸出枱邊。唔用刀時，將刀平放喺砧板上遠離邊緣嘅位置，刀刃朝向冇人會掂到嗰邊。
5. 生肉、生魚，同熟食、即食蔬果，要用分開嘅刀同砧板；如果只有一套，就先處理即食食物，處理完生肉之後，徹底清洗，再按清潔產品說明消毒，先好做下一項工作。
6. 每次只切少量。生肉分批由雪櫃拎出嚟，切完盡快放返入雪櫃冷藏或者烹調；唔好為咗練習，長時間攤喺室溫。

## 一定要養成嘅安全習慣

- 刀跌落地就退開，絕對唔好伸手接，亦唔好用腳擋。等把刀跌定先執。
- 唔好拎住刀指人、比手畫腳，或者轉身講嘢；要移開食材、聽電話或者開櫃門，就先放低把刀。
- 唔好將刀藏喺洗碗水、泡沫、抹布或者食材下面，亦唔好將刀散放喺櫃桶入面。
- 盡量喺固定位置操作。如果一定要移動，刀尖向下，刀刃避開自己同其他人，另一隻手唔好同時搬重物；唔好喺人群中間逼過。
- 遞刀時，先將刀放喺穩固枱面，等對方握住刀柄再拎走。唔好將刀尖遞畀人。
- 唔好用廚刀開罐頭、撬樽蓋、擰螺絲、剝硬殼或者拆包裝。卡刀就停止用力，唔好扭刀、敲刀背，亦唔好將食物連把刀舉起，再大力撞落砧板。
- 鋒利嘅刀一樣會𠝹傷人；「保持鋒利」係為咗減少跣刀同用蠻力，唔代表可以放鬆護手。
- 防割手套唔能夠擋住所有刺傷同斬擊；如果要用，揀適合接觸食物、尺碼合適嘅產品，按說明清洗，亦仍然要正確握刀同扶穩食材。

## 刀嘅種類：按工作揀刀

| 刀具 | 適合做啲咩 | 唔適合做啲咩 |
| --- | --- | --- |
| 中式片刀、桑刀 | 蔬菜、無骨肉切片切絲；闊刀面方便搬移食材 | 斬骨、切硬凍肉；刀身闊大唔代表可以斬骨 |
| 廚師刀 | 日常切片、切塊、切碎；弧形刀刃方便小幅度搖切 | 撬殼、扭住把刀切硬骨，薄刀刃尤其容易損壞 |
| 三德刀 | 日常處理蔬菜、魚肉、無骨肉 | 夾硬以刀尖做支點搖切、大力斬骨 |
| 削皮刀、小生果刀 | 修整細塊食材、去蒂；新手仍然應該喺砧板上操作 | 將硬食物拎喺掌心快速削切 |
| 鋸齒刀、麵包刀 | 麵包、熟軟番茄等，以輕柔拉鋸動作切開 | 斬骨；用長刀鋸切時，另一隻手尤其要遠離刀嘅移動路線 |
| 剔骨刀、片魚刀 | 熟手沿骨起肉、片魚；刀身軟硬程度視乎用途而定 | 新手徒手握住肉，朝手掌方向削切 |
| 斬骨刀 | 廠商明確容許處理嘅骨類工作 | 當成萬用刀；唔係所有骨都適合喺屋企處理 |
| 廚剪 | 剪蔥、剪包裝、處理廠商容許剪嘅軟組織 | 超出指定用途剪硬骨；處理生食之後未洗就剪熟食 |

新手通常先買一把握得穩嘅主刀、一把小刀，同一塊穩固砧板就夠；經常食麵包先再加把鋸齒刀。唔使為咗入門買成套刀。先睇用途說明，再睇長度、重量同刀柄啱唔啱自己隻手。刀身太長或者太重，都會更難控制。

不鏽鋼刀一樣會生鏽；碳鋼刀更加要及時抹乾，表面正常氧化變色，同紅啡色鏽斑係兩回事。陶瓷刀硬但脆，唔適合扭切、拍蒜、切骨或者切硬凍食物，磨刀通常要交畀專業人士。

## 認識把刀同握刀方法

### 握刀嗰隻手：穩陣最緊要

刀背係同刀刃相對嘅厚邊，刀尖喺前端，刀跟就近刀柄。部分刀嘅刀跟亦非常鋒利，手指唔可以繞到刃口下面。

全柄握法：手指包住刀柄，拇指自然收好，唔好畀手指向前滑到刀刃。適合啱啱開始練習，或者唔適合捏握嘅刀款。

捏握法：拇指同食指輕輕捏住靠近刀柄位置嘅刀身兩側，其餘手指環握刀柄；指腹要遠離下面嘅刃口。刀款適合，而且握得穩嗰陣先用，唔好捏刀尖、刀刃，或者將手伸得太前。

握力只要足夠令把刀唔會轉動就得，唔好握到手腕僵硬。手腕盡量保持自然，膊頭放鬆；食材太高或者太硬，就先改變食材形狀，唔好靠抬高手臂嚟加力。

### 扶食材嗰隻手：貓爪手唔係盔甲

1. 指尖向掌心屈曲，用指尖固定食材，指關節朝向刀嘅側面。
2. 拇指收喺食材後面，唔好伸到刀口前面；尾指亦唔好張開。
3. 刀側可以輕靠屈曲手指嘅關節，作為位置參考，但刃口要一直低過引導刀身嘅關節。唔好將刀抬到高過關節。
4. 每切一刀，先等把刀停穩，再將扶食材嗰隻手向後移少少；唔好一邊追住把刀一邊郁隻手。
5. 剩返好短嘅一小塊時就停低，平放轉個方向，或者留作其他用途。唔使切到最後一毫米。

遇到濕滑嘅肉、圓形食材，或者手指夾唔穩嘅小塊，先抹走表面多餘水分、切出平底，或者換工具。唔好單靠「貓爪手」夾硬切。

## 基本刀法同大小

尺寸只係幫手理解，唔係統一標準；要以實際食譜同所需熟度為準。同一鑊入面同一種食材，盡量切到大小一致，避免外面燶咗，入面仲係硬嘅。

| 刀法 | 做法 | 常見用途同例子 |
| --- | --- | --- |
| 切片 | 平底貼住砧板，穩定落刀，每切一刀就退一退手 | 炒薯仔片可以由大約 2—3 毫米開始練；厚薄按食譜調整 |
| 切條、切絲 | 先切片，將少量薄片疊齊或者攤開，再切長條 | 新手先由粗條開始，熟練之後再切幼絲 |
| 切粒 | 將條狀食材轉向，再橫切 | 配菜粒可以由大約 1 厘米開始練；唔好一次疊太多層 |
| 切塊 | 分成大小相近嘅塊 | 燉餸通常會比快炒切得大塊，實際睇食譜 |
| 滾刀塊 | 長條食材斜切一刀後轉動，再斜切 | 紅蘿蔔、茄子；每次轉動之前，都要先令食材離開刀刃，再停穩 |
| 切蓉 | 先切薄片、幼條、細粒，再逐少切碎 | 薑、蒜、香草；扶食材嗰隻手唔好放近刃口 |
| 拉切、推切 | 刀刃帶住水平方向嘅移動切入，唔係一路垂直大力壓落去 | 無骨肉、較軟嘅蔬菜；移動範圍唔可以掂到另一隻手 |
| 輕柔鋸切 | 鋸齒刀前後移動，減少向下壓 | 麵包、軟番茄，避免壓扁 |

搖切只適合刀款、空間同食材都啱嘅情況：小幅度移動刀柄，保持控制，唔使追求連續快剁。平直刀刃唔使模仿弧刃廚師刀嘅動作。

搬移食材優先用刮板或者手。如果用刀面，就先停刀，令刃口遠離手指，避免用刀鋒沿住砧板橫刮，令刀變鈍。唔好用手指沿住刀刃抹走黐住嘅食物。

## 切蔬菜：由穩固嘅平面開始

### 薯仔、紅蘿蔔、白蘿蔔：先切平底，再切片、絲、粒

1. 洗乾淨，按需要去皮，切走唔食得嘅部分。變綠、明顯發芽或者變壞嘅薯仔，唔好用嚟練習或者食用。
2. 圓柱形嘅紅蘿蔔可以先切成容易控制嘅段；切走一薄片，整出平底，再平底向下切。
3. 先切成厚薄相近嘅片。切絲時只疊少量放得穩嘅片，如果跣就攤開逐片切。
4. 切粒先切成等闊嘅條，再橫切。唔好將長蘿蔔豎起，再向下劈。

![圓形食材先切出平底，再平放切片、切條、切粒](images/knife-cuts.svg)

### 洋蔥：新手唔使橫住向手掌切

1. 剝走外皮同切走乾咗嘅頂端，沿根部方向對半切開；切第一刀時先固定好洋蔥，有需要可以先削出一個細平面。
2. 半個洋蔥切面向下，根部向後。順住頂端至根部嘅方向切幾刀，近根部保留少少相連。
3. 轉向後橫切成粒，利用洋蔥本身嘅分層，唔使再朝住手掌橫切一刀。
4. 切到近根部就停，將難以固定嘅末端另外平放處理，或者掉咗佢。

唔好合埋眼切洋蔥。如果流眼水影響視線，先放低把刀、離開砧板，等恢復之後先繼續。

### 青椒、甜椒、辣椒

將椒放穩，直向剖開，平放後去籽同白色內筋，再切條或者切粒。如果表皮跣，就將內側向上。處理辣椒之後避免掂眼；可以用適合接觸食物嘅手套，完成之後洗手，並清潔刀同砧板。

### 番茄、茄子、青瓜

番茄用鋒利薄刃刀輕輕拉切，或者用鋸齒刀輕輕鋸切，絕對唔好因為跣刀而突然加力。青瓜、茄子先去蒂，再直向切出穩固底面，或者對半切開平放。切滾刀塊時逐少切，每次停刀先轉動，唔好畀食材碌向刀口。

### 葉菜、蔥同香草

先洗乾淨、瀝走多餘水分，摘走壞葉。葉菜每次疊少量，輕輕捲起後切段或者切絲，唔好捲成好高嘅菜堆。蔥先切短段，再對齊處理；蔥白較跣，就減少每次處理嘅數量。香草先聚埋再切，唔好落刀嗰陣伸手執散開咗嘅葉。

### 薑、蒜同蘑菇

薑先切出平底，再切片、切絲、切蓉。蒜可以去皮後切片、切蓉，或者用壓蒜器；唔建議新手模仿用刀面大力拍蒜，尤其唔可以用陶瓷刀或者薄脆嘅刀拍。蘑菇切走唔用嘅根部，大隻嘅對半切開，再切面向下；細隻嘅如果固定唔到，可以原隻按食譜烹調。

### 南瓜、冬瓜、粟米等較硬食材

大塊南瓜、硬皮瓜類，最緊要係放得穩，同用啱工具。新手優先買切好嘅瓜塊；唔好為咗切開而敲刀背、踩刀，或者舉刀撞落砧板。把刀切入之後卡住就停，唔好左右扭動刀刃。

粟米粒可以用專用脫粒器刮出。用刀嘅話，先整出可以平放嘅穩固小段，喺低位固定，刀刃遠離扶住粟米嗰隻手，再逐面削落嚟；如果唔識穩妥固定，就買現成粟米粒。唔好將成條粟米高高豎起，喺光滑枱面上削。

## 切肉：睇肉紋，亦要睇有冇骨

### 無骨牛肉、豬肉：逆紋切片

肉上面幼長、平行嘅纖維就係肉紋。逆紋切即係刀口橫跨纖維，縮短每啖肉入面嘅長纖維；唔係固定朝住身體某個方向切。

1. 生肉要喺冷藏環境解凍；唔好切硬凍肉，亦唔好長時間放喺室溫等佢變軟。
2. 抹走表面多餘肉汁，用生肉專用嘅刀同砧板，切好嘅肉要及時放入容器。
3. 睇清楚纖維方向，將肉擺到容易橫切纖維嘅位置。如果冇平底，就先分成可以穩固平放嘅肉塊。
4. 用穩定拉切動作，切出厚薄相近嘅片；炒肉片可以由大約 2—4 毫米開始練，仍然要按食譜調整。唔好用手將肉懸空拉緊，再朝住隻手切。
5. 切絲可以先切片、再切條；燉肉就切成大小相近嘅塊。唔同部位嘅纖維方向可能有變，要轉動肉塊重新睇清楚。

![肌肉纖維平行伸延，切線橫跨纖維，縮短纖維長度](images/knife-grain.svg)

「牛橫切、豬豎切」呢類口訣，唔可以代替觀察肉嘅部位同睇食譜。要唔要逆紋、切幾厚、需唔需要保持形狀，都要配合菜式要求；需要嫩口嘅快炒無骨肉，縮短纖維通常會更容易咬。

### 雞胸肉、雞髀肉同帶骨禽肉

雞胸肉平放，去走明顯筋膜後切片或者切塊；新手唔好將手掌壓喺肉上面，再橫向片薄，可以直接買薄切肉。雞髀優先買去骨肉，攤開之後再分塊。唔好用片刀夾硬斬關節、髀骨或者急凍雞件，請店舖幫手斬件。

唔好沖洗生雞肉，以免水花飛濺，污染周圍。切完生禽肉之後，要清洗雙手、刀、砧板、枱面，同掂過嘅把手；裝過生肉嘅碟唔可以直接裝熟肉。肉切得薄，唔代表已經煮到安全熟度，烹調仍然要跟食譜同食物安全要求。

### 魚肉、蝦同海鮮

新手優先揀去骨魚柳。魚柳抹走多餘水分，平放，再輕柔拉切，避免壓爛魚肉；發現魚骨就用專用魚骨鉗夾走，再檢查，唔可以單憑「無骨」標籤就唔睇。

成條魚起骨、去皮，同貝類開殼，涉及跣手、尖刺同專用工具，可以請店舖幫手處理。蝦可以用廚剪剪開蝦背，再挑走需要去除嘅部分；唔好握喺掌心，用尖刀朝住隻手刺。蠔、椰子、蟹殼等，唔可以用普通廚刀夾硬撬開。

### 熟肉同餸尾

用乾淨、未接觸過生肉嘅刀同砧板切熟肉，按肉紋同食譜需要切片。唔好用手大力壓住啱啱起鑊、熱辣辣嘅肉，等佢降到適合操作嘅溫度先切，同時避免長時間放喺室溫。切好嘅餸尾要盡快妥善冷藏。

## 水果、麵包、豆腐同其他食材

### 蘋果、梨、柑橘

洗乾淨後喺砧板上切開。蘋果、梨先切出平面，再切瓣，平放後去芯；唔好捧住果瓣，朝掌心削走果芯。柑橘可以用手剝就用手剝，需要切片時，先切出穩固底面。

### 牛油果、芒果同有核水果

熟牛油果可以優先用專用工具。用刀嘅話，先喺砧板上固定好個果，慢慢繞住果核切開，停刀後用手將兩半分開，再用匙羹挖走果核同果肉。唔好將半個果握喺掌心，用刀劈核或者用刀尖挑核。

芒果先切出穩固底面，沿扁平果核兩側切出果肉；要切粒時，先將果肉由果皮取落砧板，再切。唔好捧住果皮𠝹格仔，令刀尖有機會穿過果皮，拮傷隻手。桃、李等切開之後，用手分開，或者用匙羹挖核，唔好用刀夾硬撬。

### 西瓜、菠蘿同硬殼果實

大西瓜、菠蘿要先考慮重量同砧板大小；控制唔到就買切好嘅份量。可以穩定操作嘅話，先切出平底，分成小塊再修皮。唔好喺會碌動嘅完整大果上橫住大力劈。椰子等堅硬外殼，需要專用工具同合適操作條件，普通廚刀唔適合。

### 麵包、蛋糕、豆腐同芝士

麵包用鋸齒刀輕輕鋸切，扶住麵包嗰隻手要遠離刀前後移動嘅路線；越切近底部就越要減力，避免突然切穿。蛋糕用乾淨長刀平穩切開，停刀之後先抹走黐住嘅食物。

豆腐輕輕放喺砧板上，用薄而鋒利嘅刀切塊，唔好用手擠壓；芝士黐刀時，減少每刀切嘅厚度，或者用合適嘅芝士刀，唔好扭住把刀撬開大塊芝士。處理果仁硬殼要用專用夾具，冰粒同硬糖亦唔好用廚刀斬。

## 清洗、抹乾同收好

1. 用完之後即刻將刀具獨立處理，握住刀柄，令刀刃遠離身體同另一隻手。
2. 用暖水、溫和清潔劑，同唔容易刮花刀面嘅清潔工具清洗。清潔方向要避開刃口，唔好用海綿或者抹布包住刀刃來回抹，亦唔好徒手抹刃口。
3. 畀生食污染過嘅刀同砧板，先去污清洗，再按適用消毒產品嘅說明處理；濃度、接觸時間，同需唔需要沖水，都要跟產品要求，唔可以隨便混合清潔劑。
4. 沖乾淨之後，小心抹乾刀面、刀柄接駁位同刀柄，避開刀刃。唔好長時間浸水，亦唔建議放洗碗碟機，尤其係木柄、碳鋼，或者廠商禁止機洗嘅刀。
5. 完全乾透之後，放入刀鞘、刀架，或者有獨立刀槽嘅櫃桶。刀架亦要保持乾淨、乾爽；磁石刀架要裝得穩固、避開小朋友，並按廠商指示拎取同放回，避免刃口碰撞。

木柄按廠商說明保養，用容許接觸食物嘅護理產品；唔好自己搽工業機油。碳鋼刀切完酸性食物之後，要盡快洗乾淨、抹乾；長期收起時，要唔要薄搽一層適合接觸食物嘅防鏽油，就按說明決定，用之前先清潔。發現生鏽、裂紋、刀柄鬆動，或者明顯崩口，要先維修或者更換。

## 磨刀、整刃同判斷鋒利程度

### 幾時需要保養

切同一種食材要用更大力、切番茄成日跣刀、將蔥葉壓爛而唔係切斷，都表示刀刃可能需要保養；亦要檢查有冇用錯刀、砧板有冇跣，或者食材係咪冇平底。

唔好用手指劃過刀鋒、剃毛，或者喺手上切紙嚟測試。可以喺砧板上，用平時嘅食材同正常切法，觀察切起嚟順唔順；有崩口就唔好繼續試切。

### 整刃棒同磨刀石有咩分別

部分鋼製整刃棒，主要幫手修正輕微歪咗嘅刃口；陶瓷棒、金剛石棒亦可能會磨走金屬。唔同刀材、硬度同刃型，對工具有唔同要求，日式薄刃刀、單刃刀或者陶瓷刀，唔可以照搬其他刀嘅保養方法。

磨刀石透過磨走少量材料，恢復刃口。冇一個角度數字適用於所有刀，應該優先跟廠商提供嘅單側角度、刃型同磨具說明。如果將兩面夾角誤當成單側角度，就會磨壞刀刃。

### 新手保養流程

1. 睇刀具說明，確認可唔可以自行磨刀、用咩磨具同角度。唔清楚就交畀專業磨刀服務。
2. 將磨刀石或者有導向功能嘅磨刀器固定喺防滑底座，保持枱面乾淨、光線充足；要唔要浸水、加水或者用油，要按磨具說明，唔好將所有磨刀石都浸水。
3. 用導向工具，或者按已經學識嘅穩定動作輕磨，手指一直遠離刀刃移動路線。唔好將磨刀棒懸空，快速揮刀表演。
4. 唔好為咗追求鋒利而大力壓，或者將刃口磨得太薄；鋸齒刀、單刃刀同陶瓷刀，要交畀熟悉嗰種刀款嘅人保養。
5. 完成之後，清走刀具同枱面上嘅金屬磨屑，抹乾收好。磨過嘅刀用起上嚟手感會唔同，先慢慢切少量食材。

磨刀幾密，取決於使用頻率同強度、刀材、砧板同手法，唔使隔固定日數就磨。用合適砧板、避免橫向刮刀刃、獨立存放，往往比成日磨刀更緊要。

## 常見問題排查

| 問題 | 先檢查 | 更穩妥嘅處理方法 |
| --- | --- | --- |
| 食材碌來碌去 | 冇平底、砧板太跣 | 停刀，切出平底，固定砧板 |
| 刀喺表皮上跣 | 刀鈍、表面濕、用錯刀 | 抹乾多餘水分，換鋒利刀或者合適嘅鋸齒刀 |
| 切片時厚時薄 | 疊得太多、退手幅度唔一致、動作太快 | 減少數量，切一刀停一停，由厚片開始練 |
| 肉畀壓爛 | 刀鈍、肉太軟、一路大力向下壓 | 冷藏令肉保持結實，換鋒利刀平穩拉切 |
| 刀卡喺硬食材入面 | 工作超出刀具能力 | 停止扭撬或者敲擊，改買切好嘅食材，或者請店舖處理 |
| 手腕痠痛 | 刀太重、枱面高度唔啱、握得太大力 | 暫停休息，調整工具同姿勢；持續痛就及時求醫 |
| 食材黐刀 | 切面濕潤或者含澱粉 | 停刀之後用合適工具移開，唔好沿住刀刃抹 |

## 分階段練習：唔計時、唔鬥快

1. 第一階段只練擺好枱面、握刀、貓爪手同停刀。揀容易固定嘅半條青瓜，或者軟硬適中嘅蔬菜，切少量厚片。
2. 第二階段用有平底嘅薯仔練切片、切條、切粒，檢查大小相近就得，唔使追求幼到髮絲咁。
3. 第三階段練洋蔥粒、椒絲同葉菜段，體會唔同食材點樣放先穩。
4. 第四階段用獨立嘅生肉刀同砧板，練切無骨肉片，先認清肉紋，再切少量，最後做好清潔消毒。
5. 每次完咗都檢討：砧板有冇郁、拇指有冇伸出嚟、有冇用蠻力壓刀、切到細小末端嗰陣有冇主動停低、把刀有冇及時收好。

每個階段都要做到可以穩定、慢慢做，先進入下一階段。未成年人應該由有能力操作嘅成年人喺現場指導，按年齡同能力揀合適工具同工作。

## 唔小心𠝹傷嗰陣

即刻放低把刀，停止接觸食材。小傷口可以用乾淨敷料或者布，持續直接按壓止血；如果有異物插咗入去，唔好自行拔出，亦唔好直接壓住異物，應該喺周圍施壓，並且求醫。敷料畀血浸透咗，就喺上面加一層，避免反覆揭開嚟睇。

止血之後，細而表淺嘅傷口可以用乾淨流動水沖洗，清潔周圍皮膚，再蓋上無菌敷料。畀傷口污染咗嘅食物要掉走，受污染嘅枱面亦要清潔。唔好喺傷口灑鹽、咖啡粉，或者用食材偏方。

出血控制唔到、噴射出血、傷口又深又大、手掌嚴重受傷、麻痺、活動受限，或者有異物時，要即刻尋求醫療協助；喺中國內地遇到緊急情況就打 120。之後如果紅腫加劇、流膿、發燒等，亦應該求醫，由醫護人員評估感染情況，同有冇需要預防破傷風。文字教學唔可以代替現場急救訓練。

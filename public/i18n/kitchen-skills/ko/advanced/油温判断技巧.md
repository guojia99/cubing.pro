# 기름 온도 판단 요령과 자주 쓰는 온도 및 단위 환산표

* 기름 온도가 120&deg;C-140&deg;C일 때: 부드럽게 튀기기[^1]와 부드럽게 볶기[^2]에 적합하다. 기름에 젓가락을 넣으면 주변에 기포가 거의 생기지 않으며, 푸르스름한 연기와 소리가 없고 기름 표면이 잔잔하다.
* 기름 온도가 150&deg;C-160&deg;C일 때: 가장 알맞은 조리 온도다. 기름에 젓가락을 넣으면 주변에 기포가 조금 생기고 푸르스름한 연기가 약간 나며, 기름이 가장자리에서 가운데로 움직인다.
* 기름 온도가 160&deg;C-180&deg;C일 때: 색을 내고 바삭하게 튀기기에 적합하다. 기름에 젓가락을 넣으면 푸르스름한 연기가 많이 올라오지만, 기름 표면은 오히려 비교적 잔잔하다.
* (참고) 기름 온도를 잴 수 있는 적외선 온도계를 구입하는 것이 가장 좋으며, 온도계는 주의해서 사용한다.

> 온라인 동영상 강좌에서 말하는 기름 온도의 ‘몇 할’은 10할을 300&deg;C로 잡은 상대적인 값이다.
> 즉, 기름 온도 n할은 T_n = 30n [섭씨도]이다.
> 온도 환산 공식
> C = 5/9 *(F - 32)
> 또는
> F = 9/5*C + 32

위 설명을 바탕으로 만든 표다. 오차 범위는 전문적인 측정 자료에 근거하지 않는다.

| -18±4 | 급속 냉동(냉동) | -0.4±4 |
| 4±2 | 냉장 보관 | 40±4 |
| 30±10 | 실온 | 86±18 |
| 60±10 | 2할 | 140±18 |
| 90±10 | 3할 | 194±18 |
| 120±10 | 4할 | 248±18 |
| 150±10 | 5할 | 302±18 |
| 180±10 | 6할 | 356±18 |
| 210±10 | 7할 | 410±18 |
| 240±10 | 8할 | 464±18 |
| 270±10 | 9할 | 518±18 |
| 300±10 | 10할 | 572±18 |

* ^1: 부드럽게 튀기기는 작게 썰거나 편 또는 길쭉한 모양으로 썬 재료에 튀김옷을 입혀 기름에 넣고, 70~80% 정도 익도록 튀기는 방법이다.
* ^2: 부드럽게 볶기는 육질이 연한 동물성 재료를 채, 편, 주사위, 막대 모양 등으로 썰고 달걀흰자와 전분으로 얇게 코팅한 다음, 따뜻한 기름에서 서로 떨어지도록 풀어 익히고 체에 부어 여분의 기름을 빼는 방법이다.

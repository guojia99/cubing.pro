# 무엇을 먹을지 결정하는 방법

무엇을 먹을지 결정하는 것도 요리하기 전 제가 겪는 큰 고민 중 하나입니다. 그래서 수학으로 설명해 볼 수밖에 없겠습니다.

## 계산 방법

### 고기 요리와 채소 요리의 개수 계산하기

* 요리 개수 = 인원수 + 1.
* 고기 요리는 채소 요리보다 하나 많거나 개수가 같으면 됩니다.

이렇게 고기 요리와 채소 요리의 개수를 구한 뒤, 앞 단계의 레시피에서 고르면 됩니다.

#### 형식 언어로 표현하기

인원수가 `N`일 때,
`채소 요리 수`를 `a`, `고기 요리 수`를 `b`라고 둡니다.
`N`, `a`, `b`는 모두 정수입니다.

그러면 다음 연립부등식이 성립합니다.

* a + b = N + 1
* a ≤ b ≤ a+1

이를 풀면 다음과 같습니다.

```javascript
const a = Math.floor((N+1)/2);
const b = Math.ceil((N+1)/2);
```

### 요리 선택하기

* 인원이 8 명을 넘으면 고기 요리에 생선 요리를 추가하는 것을 고려하세요.
* 아이가 있다면 단맛이 나는 요리를 추가하는 것을 고려하세요.
* 특색 있는 요리나 자신 있는 요리를 추가하는 것을 고려하세요.
* 고기 요리를 정할 때는 모두 같은 동물의 고기로 만들지 않도록 주의하세요. 고려할 순서는 `돼지고기`, `닭고기`, `소고기`, `양고기`, `오리고기`, `생선살`입니다.
* 이상한 동물을 고기 요리 재료로 고르지 마세요.
